# 리더보드

### 리더보드의 갱신 주기는 어떻게 되나요?  
뒤끝의 리더보드는 유저가 점수를 갱신함과 동시에 결과가 실시간으로 랭킹에 반영됩니다.  
또한, 랭킹 조회 시 조회 당시의 랭킹 순위를 그대로 보여주게 됩니다.  
단, 실시간 반영을 위해 갱신/조회를 자주 호출하는 경우 그만큼 비용이 높게 발생할 수 있으니 게임 운영에 맞추어 적절하게 호출할 수 있도록 구성하시는 것을 권장 드립니다.  
&nbsp;  
&nbsp;  

### 리더보드 순위 조회 시 불러올 수 있는 순위 인원은 몇명인가요?  
버전에 따라 조회 가능한 인원이 상이합니다.  
최댓값을 초과한 인원도 조회도 가능하나, 추가 호출을 통한 조회가 이루어져야 합니다.  
- SDK 5.11.0 이상 버전 - limit 50, gap 25  
- SDK 5.11.0 미만 버전 - limit 100, gap 50  
&nbsp;  
&nbsp;  

### 리더보드 초기화 시간은 어떻게 되나요?  
리더보드 생성 시 설정한 시간에 초기화 및 보상 지급이 이루어지며, 해당 시간으로부터 1시간 동안은 리더보드를 갱신할 수 없습니다.  
&nbsp;  
&nbsp;  

### 리더보드 기간이 종료되어도 순위를 유지시킬 수 있나요?  
아니요.  설정한 랭킹 기간이 종료되면 순위 정보는 자동으로 초기화됩니다.  
&nbsp;  
&nbsp;  

### 유저가 리더보드 내 본인의 순위 정보를 삭제할 수 있나요?  
아니요. 클라이언트를 통한 리더보드 삭제 기능은 제공되지 않고 있습니다.  
콘솔을 통해서 관리자만이 삭제할 수 있습니다.

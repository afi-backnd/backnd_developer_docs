# BASE SDK

### BASE SDK 현황

|버전 구분|현재 상태|향후 일정|
|---|---|---|
|6.0.0 ~|준비 중|출시 시점부터 정식 지원 단계 시작|
|<b>5.10.2 ~</b>|<b>지원 중</b>|<b>정식 지원 버전</b>|
|~5.9.x|지원 종료 예정|2026.07.31 지원 종료 (EoS)|
|~4.x.x|기능 종료 예정|2026.07.31 기능 종료 (EoL)|


:::warning SDK 업데이트 주의 안내
- **5.12.0 이상 버전부터 뒤끝의 통신 라이브러리가 변경되었습니다.**  
5.11.9 이하 버전에서 상위 버전으로 업데이트를 하는 경우 관련 내용을 꼭 확인하신 후 업데이트 해주시고,  
업데이트 후에는 반드시 충분한 테스트를 진행하신 후 라이브에 반영해 주시기 바랍니다.  

- **5.12.0 ~ 5.14.1 버전에서 뒤끝매치 일부 핸들러가 정상적으로 작동하지 않습니다.**  
뒤끝매치를 이용하는 경우 해당 버전을 제외하고 이용해 주시기 바랍니다.  

- **5.18.7 버전부터 랭킹, 차트, 확률, 약관 및 정책, 길드의 구버전 함수들이 삭제되었습니다.**  
신규 버전 함수들이 제공됨에 따라 Deprecated 되었던 함수들이 삭제되었습니다.  
삭제된 함수에대한 상세한 내용은 [**[업데이트 노트]**](/update-note-backend/backend-5-18-7)를 통해 확인할 수 있습니다.
:::

# 게임로그

### 게임 로그 저장 기한은 얼마나 되나요?  
파라미터 값을 통해 설정할 수 있으며 게임 로그의 저장 기한은 최대 90일입니다.  
- 게임 로그 V2 함수 : 최초 저장한 로그의 파라미터 값이 해당 행동유형의 기한으로 고정 설정 (이후 변경 불가)
- 게임 로그 V1 함수 : 매 요청의 파라미터 값에 따라 저장된 로그 데이터별로 각각 기한이 설정
&nbsp;  
&nbsp;  

### 로그 저장 기한 경과로 삭제된 로그를 복구할 수 있나요?  
로그의 기한이 경과 시 자동 삭제되어 복구가 불가합니다.

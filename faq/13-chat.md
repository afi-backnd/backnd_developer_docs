# 채팅

### 일정 시간동안 채팅에 참여하지 않으면 접속이 끊기나요?  
채팅 서버 접속 이후 미사용으로 서버 접속이 종료 되지 않습니다.  
또한 네트워크 문제, 서버 업그레이드 등 서버 접속이 끊기는 모든 경우에는 자동으로 재접속하도록 되어있으며, 정상 연결이 될때까지 재접속이 시도됩니다.  
&nbsp;  
&nbsp;  

### 네트워크 문제등으로 인해 접속이 끊기는 경우 재접속하려면 어떻게 해야하나요?  
뒤끝의 채팅은 유저의 네트워크가 변경되거나 리스가 발생할 경우 자동으로 재접속 되도록 구성되어 있습니다.  
&nbsp;  
&nbsp;  

### 채팅 BASIC 요금제 이용 중인데, 콘솔에서 채널 선택 시 채팅 내용이 보이지 않아요.  
채팅 BASIC 요금제는 Pro 기능(대화 기록 저장, 비속어 필터, 신고 및 제재)이 제공되지 않습니다.  
대화 기록 확인이 필요한 경우, 채팅 요금제를 FREE 또는 BUSINESS로 이용해 주셔야 합니다.  
&nbsp;  
&nbsp;  

### 이 전 대화 내역을 불러오는 기능이 있나요?  
BUSINESS 요금제 이용 시에 한하여 제공되는 기능으로, 콘솔의 설정 메뉴를 통해 불러올 메시지의 기간 및 메시지 수를 설정하고 이용할 수 있습니다.

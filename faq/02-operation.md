# 운영

### 임시 공지사항은 이미지를 첨부할 수 없나요?
임시 공지사항은 로그인 없이 간단한 공지사항을 확인할 수 있도록 제공되는 기능입니다.  
이미지 기능은 제공되지 않습니다.  
&nbsp;  
&nbsp;  

### 공지사항과 이벤트를 국가별로 작성해 제공하고 싶은데, 국가 선택이 불가합니다.
공지사항의 국가 선택은 유저의 국가 코드 정보를 기반으로 하고 있습니다.  
제공하고자 하는 국가 코드로 생성된 유저 정보가 없다면 선택이 불가합니다.
&nbsp;  
&nbsp;  

### 공지사항과 이벤트의 이미지 및 버튼, URL은 국가별로 제공할 수 없나요?
공지사항/이벤트의 제목 및 내용에 한해 국가별로 제공이 가능합니다.  
공지사항의 이미지, 버튼, URL은 단일 정보로만 사용 가능하고 국가별로 설정하는 기능은 제공되지 않습니다.  
&nbsp;  
&nbsp;  


### 약관 및 정책 페이지를 한국어와 영어 외에 설정할 수 없나요?
페이지 내 기본 틀은 한국어/영어에 한하여 제공됩니다.  
이용 약관 및 개인정보 처리 방침의 경우 세부 내용은 원하는 언어로 설정이 가능합니다.  
&nbsp;  
&nbsp;  

### 1:1 문의의 기본 양식을 국가별로 제공하고 싶은데, 선택이 불가합니다.
1:1 문의의 국가/언어 선택은 SDK 5.11.0 이상 버전에서 사용 가능하며, 유저의 국가/언어 정보를 기반으로 하고 있습니다.  
제공하고자 하는 국가/언어로 생성된 유저 정보가 없다면 선택이 불가합니다. (국가 코드가 아닌 국가/언어 정보를 기반으로 합니다.)
&nbsp;  
&nbsp;  

### 약관 및 정책 기능 이용 시 개행 문자를 제공해주나요?
개행 문자열을 별도로 제공하고 있지 않습니다.  
직접 개행에 필요한 특수 문자를 삽입해 주시거나, \n을 통해 치환하는 방법 등으로 이용해 주시기 바랍니다.  
&nbsp;  
&nbsp;  

### 로그인 없이 서버점검을 알리는 방법이 있나요?
서버상태 조회 및 임시공지 조회 기능은 로그인 없이 호출이 가능합니다.  
해당 기능을 사용하여 각 상황에 따라 다음과 같이 구성해주시면 원하는 메시지를 띄워줄 수 있습니다.  
  
1. 점검 시간 중 게임을 실행한 경우  
GetServerStatus 함수 호출 => 점검 코드 2 리턴(이 과정 대신 로그인 호출 후 점검 에러 리턴시 처리를 하셔도 무방합니다) => GetTempNotice 호출 => 임시공지에 등록한 메시지 노출  
  
2. 플레이 중 점검시간이 된 경우  
서버 점검 오류 발생 => 게임을 중단시키고 메인화면으로 이동 => 1번과 동일과정을 거치거나, 바로 GetTempNotice 함수를 호출하여 임시공지에 등록한 메시지를 노출

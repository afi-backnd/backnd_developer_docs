# 우편

### 모든 우편 종류를 한 번에 조회하거나 수령할 수는 없나요?  
뒤끝의 우편은 종류에따라 관리자, 리더보드 보상, 유저, 쿠폰 우편으로 분류됩니다.  
통합 조회 혹은 통합 수령은 제공되지 않아, 조회/수령하고자 하는 우편의 종류를 지정하여 호출해 줘야만 합니다.  
&nbsp;  
&nbsp;  

### 리더보드 보상 우편의 제목이 설정값과 다른거 같아요.  
리더보드의 보상 우편은 기본적으로 [리더보드 이름] + [설정 제목] + [순위]로 발송됩니다.  
우편 조회 시 리턴값으로 Title과 postTitle 이 제공되며,  
Title은 위 안내드린 기본 양식으로 제공, postTitle은 언어별로 [설정 제목]으로 제공됩니다.  
필요한 정보를 잘 확인하여 이용해 주세요.  
&nbsp;  
&nbsp;  

### 반복 우편과 예약 우편은 같은 시간에 발송할 수 없나요?  
동시간에 설정된 반복 우편과 예약 우편 일정이 겹치게 되는 상황에서 예약 우편은 취소됩니다.  
반복 우편의 일정을 고려하여 예약 우편은 시간 간격을 두고 발송해 주세요.  
&nbsp;  
&nbsp;  

### 한번에 몇명의 유저에게 우편을 발송할 수 있나요?  
전체 우편의 경우 발송 시점의 전체 유저를 대상으로 발송되며,  
개별 우편의 경우 한번에 최대 1,000명의 유저에게 발송할 수 있습니다.  
&nbsp;  
&nbsp;  

### 우편의 만료 기간은 어떻게 되나요?  
각 우편의 종류별로 만료 기간이 상이합니다.  
- 관리자 우편 : 하루 이내(1, 3, 6, 12, 24시간), 7일, 15일, 30일까지 설정할 수 있습니다.  
- 리더보드 보상 우편 : 7일로 고정되어 제공됩니다.  
- 유저 우편 : 15일로 고정되어 제공됩니다.  
- 쿠폰 우편 : 웹페이지를 통해 쿠폰을 사용하면 만료 기간 없이 언제라도 수령할 수 있습니다.

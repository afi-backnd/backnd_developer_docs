:::danger 5.16.2 지원 종료
특정 상황에서 사용에 문제가 있는 에러가 발견되어 해당 버전의 지원이 종료되었습니다.  
- [데이터 처리] 언마셜링이 문화권에 영향을 받아 잘못 parsing 되는 문제.  

해당 이슈는 5.16.3 버전에서 수정이 되었으므로 5.16.3 버전을 사용해 주시기 바랍니다.
:::

:::info 업데이트 요약
[클라우드 세이브] 업로드 시, 제한 용량 계산에 오류가 있던 부분을 수정했습니다.  
[실시간 알림] 재연결 시도가 실패했을 때, 알림을 주는 이벤트 핸들러를 추가했습니다.  
:::

## 5.16.2 Update
**[Fixes]**
- 클라우드 세이브에서 데이터 업로드 시, white-space를 제거하고 용량을 계산하도록 수정했습니다.  
- 실시간 알림에서 재연결 시도가 실패했을 때, 알림을 받을 수 있도록 이벤트 핸들러를 추가했습니다.  
- 실시간 알림에서 현재 연결된 상태인지를 확인할 수 있는 속성값을 추가했습니다.

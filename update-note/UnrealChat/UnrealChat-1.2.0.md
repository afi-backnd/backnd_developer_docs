## 1.2.0 Update
* **채팅 SDK의 모든 함수가 Backend에서 Backnd로 변경되었습니다.**
* 뒤끝 Base SDK 외의 서버와 연동가능한 커스텀 인증 기능이 추가되었습니다.
* 채팅 번역 기능이 추가되었습니다.
* 자동 확장 로직이 개선되었습니다.
* 언리얼 SDK가 추가되었습니다.
* 채팅 관련 API를 호출할 수 있는 Platform API 기능이 추가되었습니다.

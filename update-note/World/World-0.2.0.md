## 0.2.0 Update
**[Updates]**
- World SDK에서 Database 모듈이 제거
	 - World SDK에서 Database 모듈이 제거되었습니다. 2026년 1월에 런칭 하는 Database 서비스를 이용해 주시기 바랍니다.
- NetworkScene 기능 추가
	 - NetworkScene 기능이 추가되었습니다. NetworkScene 기능을 이용해 인스턴스 던전, 전장 등의 기능을 구현할 수 있습니다.
- 파티 시스템 추가
	 - 파티 시스템이 추가되었습니다. 파티 시스템을 이용해 인스턴스 던전, 레이드 등의 기능을 구현할 수 있습니다.

**[Fixes]**
- NetCode 최적화
	 - NetCode의 성능 최적화가 진행되었습니다. 네트워크 지연시간이 감소하고, 처리량이 향상되었습니다.

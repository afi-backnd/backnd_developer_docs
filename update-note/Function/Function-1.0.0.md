## Versions
뒤끝 펑션 SDK는 뒤끝 베이스 5.17.0을 베이스로 하고 있습니다.  

## 1.0.0 Update
**[Update]**
- 펑션 함수들이 뒤끝 베이스 5.17.0 버전을 기반으로 동작하도록 업데이트 하였습니다.  
  - 기존에 동작하지 않던 일부 기능과 클라우드 세이브를 포함한 몇몇 기능들은 펑션에서 동작하지 않습니다.  
  - 자세한 내용은 [[뒤끝 기능 요청]](/sdk-docs/function/request/request)문서에서 확인 가능합니다.  
- 펑션 디버거와 템플릿이 비동기 방식(async)으로 동작하고 테스트 할 수 있도록 수정하였습니다.

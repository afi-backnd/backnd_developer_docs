:::info 업데이트 요약
[Unity] 뒤끝 베이스 SDK의 액세스 토큰이 재발급되었을 경우, 채팅 서버의 재접속이 실패하던 에러가 픽스되었습니다.
:::

:::danger 함수 변경 안내  
채팅 SDK의 모든 함수가 Backend에서 Backnd로 변경되었습니다.  
기존 함수를 그대로 사용하는 경우 에러가 발생하게 되니, 반드시 변경된 함수를 꼭 확인해 주세요.  
:::  

<!--truncate-->

:::info 뒤끝베이스 SDK 5.11.9 이상 안내
BackndChat-1.2.1 이상을 사용하실 경우에는 Backend SDK 버전이 5.11.9 이상이어야 합니다.  
채팅 기능만 사용할 경우에는 아래 SDK만 import해 주시기 바랍니다. (뒤끝베이스는 로그인 기능 외 사용 불가)
:::

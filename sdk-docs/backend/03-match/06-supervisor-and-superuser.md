# 방장

매칭 서버에서 대기방을 생성한 유저입니다.  
방장 권한은 다른 유저에게 넘겨줄 수 없습니다.  
방장은 아래 권한을 가지고 있습니다.  
(일반 유저는 해당 기능을 사용할 수 없습니다.)

- 매칭 신청
- 매칭 신청 취소
- 유저 강퇴
- 대기방 삭제

# 슈퍼 게이머

매칭이 성사되면 서버에서 매칭이 성사된 유저들 중 1명을 게임방에서의 슈퍼 게이머로 지정합니다.  
즉 서버에서 지정한 게임방의 방장입니다.  

- **매칭 서버 대기방에서의 방장 여부와는 관계없이 매칭된 유저들 중 1명이 랜덤하게 슈퍼 게이머로 지정됩니다.**  
  - 대기방에서의 방장과 게임방에서의 슈퍼 게이머가 동일하면 유저가 어뷰징 등 방장 권한을 악용할 수 있기 때문입니다.  
- 슈퍼 게이머 유저가 게임 서버와 연결이 끊기면 자동으로 현재 게임방에 존재하는 유저 중 한 명이 슈퍼 게이머 유저로 지정됩니다.  
  - 슈퍼 게이머 변경 메시지에 대해서는 [슈퍼 게이머 변경 개발자 문서](/sdk-docs/backend/match/ingame-server/change-super-gamer)를 참고해 주세요.

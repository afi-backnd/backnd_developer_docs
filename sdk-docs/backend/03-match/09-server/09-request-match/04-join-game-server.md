# 인게임 서버 접속

매칭이 성사되어 `OnMatchMakingResponse` 이벤트의 ErrInfo가 Success로 호출된 경우,
성사된 매칭의 **MatchCardIndate**와 **RoomInfo**를 확인할 수 있습니다.  

이 정보를 이용하여 게임 상태를 설정하고,
인게임 서버 주소 및 게임방 토큰을 확인하여 인게임 서버 접속을 할 수 있습니다.  

## MatchCardIndate

어떤 매칭 카드가 매칭되었는지 확인하기 위한 Key 값입니다.  
[GetMatchList 함수](/sdk-docs/backend/match/get-list)에서 리턴된 값에서 해당 Key 값을 이용하여 어떤 매칭이 성사되었는지 확인할 수 있습니다.  

- 혼자서 매칭을 신청한 경우 로컬에 신청한 매칭에 대한 정보를 가지고 있을 수 있습니다.  
- 다른 유저를 초대하여 매칭을 신청한 경우 게임 기획에 따라 방장이 아닌 팀원은 어떤 매칭이 성사되었는지 알 수 없을 수도 있습니다.  
  이때 **해당 Key 값을 이용하여 자신이 참여해야 되는 게임의 정보**를 알 수 있습니다.  

## RoomInfo

접속해야 할 인게임 서버 주소, 포트 번호, 접속할 게임방의 토큰 값, 그리고 샌드박스 매칭 여부가 포함되어 있습니다.  
해당 인자의 자세한 설명은 [인자/리턴 클레스 정보 문서](/sdk-docs/backend/chat/basic)를 참고해 주세요.  

- 서버 주소와 포트 번호를 이용하여 인게임 서버에 접속할 수 있습니다.  
- 게임방의 토큰 값을 이용하여 게임방에 접속할 수 있습니다.  
- 샌드박스 매칭 여부를 이용하여 샌드박스 매칭 여부 확인 후 게임 로직을 처리할 수 있습니다.

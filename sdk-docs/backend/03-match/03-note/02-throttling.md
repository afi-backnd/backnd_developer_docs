# 쓰로틀링(Throttling)

클라이언트에서 서버로 전송할 수 있는 데이터 & 채팅 메시지에는 한 번에 최대로 보낼 수 있는 양이 제한되어 있어 SDK에서 쓰로틀링이 발생합니다.  

## 데이터 송신 제한량

- 데이터를 1초에 최대 10KB까지 송신할 수 있습니다.  
  - 서버에서 슈퍼 게이머로 지정된 클라이언트의 경우 1초에 최대 30KB까지 송신할 수 있습니다.  
- 1초의 기준은 **절대시간**입니다. 이전 송신 데이터와의 데이터 크기 합이 아닙니다.  
  > 예를 들어,
      39초 ~ 40초 사이에 송신할 수 있는 데이터의 최대 크기는 10KB입니다.  
      39초 ~ 39.5초 사이에 총 9KB 크기의 데이터를 송신해도 40초 ~ 40.5초 사이에 총 10KB 크기의 데이터를 송신할 수 있습니다.  
      이때 39.5초 ~ 40초 사이에는 총 1KB 크기의 데이터만 송신할 수 있습니다.  

## 쓰로틀링 걸린 데이터의 처리

쓰로틀링에 걸린 데이터는 서버로 송신이 되지 않습니다.  
해당 데이터는 SDK에서 **재전송하지 않고 바로 소멸되게 됩니다.**
쓰로틀링 걸린 데이터의 재전송 등의 작업은 클라이언트에서 제공해야 합니다.

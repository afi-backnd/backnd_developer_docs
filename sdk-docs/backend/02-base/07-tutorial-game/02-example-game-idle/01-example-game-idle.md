# BackendHero : 방치형

BackendHero : 방치형은 뒤끝 베이스 기능을 활용하여 개발한 방치형 게임입니다.  

## 라이센스

TheBackendMatch는 [BSD-2-Clause](https://opensource.org/licenses/BSD-2-Clause) 라이센스를 따릅니다.  

> 소스코드의 수정, 사용, 상업적인 이용이 가능합니다.  
> 소스코드 이용에 따른 책임, 보증은 하지 않습니다.  

해당 유니티 패키지 파일에는 게임 실행을 위한 유니티 무료 에셋인 2D 스프라이트 리소스가 일부 포함되어 있습니다.

## 포함된 기능

'BackendHero : 방치형' 게임은 아래의 뒤끝베이스 기능들을 포함하고 있으며, 방치형에 적합한 베이스의 다양한 기능들이 추가될 예정입니다.  

### 뒤끝 베이스 기능

| 기능        | 설명                                        |
| ----------- | ------------------------------------------- |
| 커스텀 계정 | 커스텀 회원가입 및 로그인                   |
| 토큰 로그인 | 뒤끝 액세스 토큰을 이용한 토큰 로그인       |
| 닉네임      | 닉네임 수정                                 |
| 정책        | 개인정보처리방침 및 서비스 이용약관 안내    |
| 차트        | 차트 읽어오기 및 캐싱                       |
| 게임 정보    | 게임 정보 업데이트 및 불러오기               |
| 트랜잭션    | 게임 정보 일과 업데이트 및 조회              |
| 자동 저장   | 코루틴을 이용한 일정주기마다 게임 저장      |
| 랭킹        | 랭킹 불러오기 및 일정주기마다 업데이트      |
| 우편        | 일정 주기마다 발송된 우편이 존재하는지 체크 |
| 게임 로그   | 에러 발생 시 에러 정보 삽입                 |
| 에러 핸들러 | 점검, 다른 기기 접속 오류 공통 에러 핸들링  |
| SendQueue   | SendQueue를 이용하여 데이터 송신            |

### 추가 예정 기능

| 기능            | 설명                                      |
| --------------- | ----------------------------------------- |
| 친구            | 랜덤 조회를 이용한 친구 추천 및 친구 목록  |
| 길드            | 랜덤 조회를 이용한 길드 추천 및 길드 목록 |
| 이벤트/공지사항 | 이벤트 및 공지사항 기능                   |
| 쿠폰            | 쿠폰에 따른 아이템 지급 및 저장           |
| 뽑기            | 뽑기 결과에 따른 아이템 지급 및 저장      |
| 뒤끝챗          | 채팅 기능                                 |

# Food Truck Venture

Food Truck Venture는 뒤끝 베이스 기능을 활용하여 개발한 방치형 타이쿤 게임입니다.  

## 라이센스

Food Truck Venture는 [BSD-2-Clause](https://opensource.org/licenses/BSD-2-Clause) 라이센스를 따릅니다.  

> 소스코드의 수정, 사용, 상업적인 이용이 가능합니다.  
> 소스코드 이용에 따른 책임, 보증은 하지 않습니다.

## 스토어에서 게임 다운로드

Food Truck Venture를 Android / iOS 버전을 스토어에 다운로드하여 플레이 할 수 있습니다.

- Android 버전 : [구글 플레이 스토어 링크](https://play.google.com/store/apps/details?id=com.backnd.foodtruckventure)
- iOS 버전 : [애플 앱스토어 링크](https://apps.apple.com/us/app/foodtruckventure/id6748892925?l=ko)

## 포함된 기능

'Food Truck Venture' 게임은 아래의 뒤끝베이스 기능들을 포함하고 있습니다. 

### 뒤끝 베이스 기능

| 기능        | 설명                                |
| ----------- | -----------------------------------|
| 로그인 기능 | 구글/게스트 회원가입 및 로그인 처리    |
| 토큰 로그인 | 뒤끝 액세스 토큰을 이용한 토큰 로그인  |
| 닉네임      | 유저가 사용하는 닉네임 수정           |
| 차트        | 차트 읽어오기 및 저장                |
| 확률        | 아이템 뽑기                         |
| 유저 정보   | 유저 정보 저장, 업데이트 및 불러오기  |
| 리더보드    | 리더보드 불러오기                     |
| 우편        | 우편 확인 수령 삭제                   |
| 인앱 결제   | 유료아이템 구매                        |
| 영수증 검증 | 아이템 구매 여부 확인, 구매 복원         |
| 버전 관리   | 서버를 통한 게임 버전 제어              |
| 서버 상태 확인| 서버 점검 , 활성화, 중지 상태 확인     |
| 공지 사항   | 게임 관련 이슈 전체 공지               |

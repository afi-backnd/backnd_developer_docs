# 콘솔에서 쿠폰 생성하기

## 콘솔에서 쿠폰 생성

뒤끝 콘솔 `뒤끝 베이스 > 쿠폰 관리`에서 **쿠폰 등** 버튼을 클릭합니다.  

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/coupon/coupon-console-create.png" />

쿠폰명, 유효기간, 쿠폰 분류, 중복 사용 여부, 발행 개수를 입력합니다.  
중복 사용 여부가 허용일 경우에는 한명의 유저가 해당 쿠폰의 다른 시리얼 번호를 가진 쿠폰들을 중복으로 사용할 수 있습니다.  

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/coupon/coupon-console-detail1.png" />

이후 지급 아이템 추가 버튼을 클릭 후, 지급 아이템을 선택합니다.  

만약 지급 아이템을 선택할 수 없는 경우에는 **우편 기능 사용이 가능한 아이템 차트**가 존재하지 않아 발생할 수 있습니다.  
이러한 경우에는 [Step 1. 사전 준비](/sdk-docs/backend/base/guideline/coupon/before)를 참고하여 우편 이용이 가능한 아이템 차트를 생성해주세요.  

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/coupon/coupon-console-detail2.png" />

지급 아이템 생성이 완료되었다면 확인을 눌러 쿠폰을 생성합니다.  

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/coupon/coupon-console-detail3.png" />

**발행 개수에 따라 쿠폰이 생성되는 시간이 증가할 수 있습니다.**  

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/coupon/coupon-console-create-end.png" />

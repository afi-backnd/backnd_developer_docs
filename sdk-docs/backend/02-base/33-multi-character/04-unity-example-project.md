# Unity 예제 프로젝트

Unity 예제 프로젝트에서 계정 로그인부터 캐릭터 생성·조회·선택·삭제, 캐릭터별 게임 정보 저장까지 전체 흐름을 확인할 수 있습니다.

## 주요 내용

- 기존 계정의 멀티 캐릭터 계정 전환
- 캐릭터 생성, 목록 조회, 선택, 삭제
- 캐릭터별 `UserData` 조회, 생성, 갱신
- 자동 전투와 능력치 강화 결과 저장

## 프로젝트 확인

예제는 Unity `2022.3.62f3`, 뒤끝 SDK `5.18.14`를 기준으로 작성되었습니다. 설치 방법, 실행 준비, 전체 소스 코드는 GitHub 저장소에서 확인하세요.

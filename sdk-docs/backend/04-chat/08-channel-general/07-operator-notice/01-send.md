# ChatToGlobal

:::warning 채팅(신버전) 출시로 뒤끝챗 지원이 종료되었습니다.  
뒤끝챗은 모든 업데이트와 지원이 종료되었습니다.  
기존 뒤끝챗을 활성화한 프로젝트에 한하여 25년 2월 28일까지만 이용 가능합니다.  

25년 3월 1일부터 뒤끝챗의 서비스가 종료되어 기존 뒤끝챗을 이용하던 프로젝트의 경우도 더 이상 이용이 불가합니다.  
새롭게 출시된 <a href="https://docs.thebackend.io/sdk-docs/chat/intro">**채팅**</a>을 이용해 주세요.
:::

public void **ChatToGlobal**(string **Message**);

## 파라미터

| Value   | Type   | Description      |
| :------ | :----- | :--------------- |
| Message | string | 공지 메시지 내용 |

## 설명

뒤끝 콘솔 **뒤끝챗-공지관리**에서 운영자로 등록된 유저는 클라이언트에서 공지 메시지를 보낼 수 있습니다.  
또한 뒤끝 콘솔 **뒤끝챗-공지관리**에 있는 공지 발송을 통해 ChannelType 별로 공지 메시지를 보낼 수 있습니다.  

## 운영자 공지 보내기

운영자로 등록된 유저가 공지 메시지를 보내는 방법입니다.  

- 운영자 공지 채팅 보내기는 채팅을 보낼 운영자가 채팅 채널(일반, 길드 둘 다 가능)에 접속해 있어야 발송할 수 있습니다.  
- 운영자 공지는 게임 내 모든 '일반 채널'에만 전달되며 길드 채널에는 전달되지 않습니다.(길드 채널만 사용하는 게임일 경우에는 뒤끝 콘솔의 공지 기능을 이용해 주시기 바랍니다.  
- 운영자로 등록된 계정의 전체 채팅(공지)은 차단/도배방지/욕설 필터링에서 제외되며 유저들에게 예외 없이 무조건 보여집니다.  
- 운영자 공지 채팅을 송신할 때 에러코드는 **OnGlobalChat의 ErrInfo**에서 확인할 수 있습니다.  
- 공지 메시지의 최대 길이는 512byte입니다.  

> 공지 받기, 보내기 기능은 Backend-4.5.0 이상 버전에서만 사용할 수 있습니다.  
> 뒤끝 콘솔의 운영자 등록은 자정(24:00)을 기준으로 업데이트됩니다

## Example

```js
Backend.Chat.ChatToGlobal("[안내] 3시부터 이벤트를 시작할 예정입니다.");
```

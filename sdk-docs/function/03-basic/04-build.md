# 빌드

개발사에서 제작한 프로젝트를 빌드하기 위해서는 Visual Studio 환경에서 빌드를 하는 것이 아닌 뒤끝에서 제공하는 Backend CLI를 이용하여 빌드를 수행해야 합니다.  

- 뒤끝펑션은 개발 환경인 윈도우가 아닌 리눅스 환경에서 동작합니다.  
- 빌드 시 뒤끝펑션에서 사용하는 여러 가지 커스텀 빌드 설정이 필요합니다.  
- **반드시 Backend CLI를 이용하여 빌드 후 그 결과물을 서버로 배포해야 합니다.**  

빌드 하는 법에 대해서는 Backend CLI [빌드](/sdk-docs/function/cli/build) 문서를 참고해 주세요.

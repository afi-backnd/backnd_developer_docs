# 응답 시간

뒤끝펑션을 서버에 배포하면 뒤끝 SDK의 뒤끝베이스 기능으로 함수를 호출할 수 있습니다.  
뒤끝펑션의 응답 시간은 **함수 실행 시간 + 통신 시간**이며 **평균 300ms 이하**입니다. 다만 아래와 같은 경우에는 응답 시간이 더 길어질 수 있습니다.  

## Cold Start

뒤끝펑션은 **서버에 배포되는 즉시 활성화되지 않고, 함수가 호출될 때 활성화**됩니다.  
비활성화된 함수를 호출하면 함수를 활성화한 뒤 실행하므로 응답 시간이 약 5000ms 이상 걸릴 수 있습니다.  
아래의 경우가 Cold Start입니다.  

- 함수를 서버에 배포한 뒤 처음 호출한 경우
- 함수를 오랫동안 사용하지 않다가 호출한 경우
- 함수를 새로 배포한 뒤 처음 호출한 경우

## Warm Start

활성화된 함수를 호출하면 응답 시간은 평균 300ms 이하입니다.  

## 함수 비활성화

활성화된 함수는 아래의 경우 다시 비활성화됩니다.  

- 함수를 새로 배포한 경우
- 함수를 오랫동안 사용하지 않은 경우

## 뒤끝펑션 안에서 여러 뒤끝 함수 호출

일반적으로 뒤끝펑션 안에서 뒤끝 함수를 1~2개 호출하는 것은 응답 시간에 큰 영향을 주지 않습니다.  
하지만 뒤끝 함수를 3개 이상 호출하면 응답 시간에 영향을 줄 수 있습니다.  
**뒤끝 함수를 호출할 때마다 응답을 기다려야 하므로, 뒤끝펑션 안에서 호출하는 뒤끝 함수가 많을수록 응답 시간이 길어집니다.**  

## 함수 실행 시간이 오래 걸리는 경우

서버는 모든 연산을 마친 뒤 응답합니다.  
따라서 개발사가 작성한 로직이 복잡하고 **연산량이 많아 함수 실행 시간 자체가 오래 걸리면 응답 시간이 길어질** 수 있습니다.

# 뒤끝 기능 호출

뒤끝펑션 안에서는 유니티에서 뒤끝 SDK로 호출하는 것과 같은 방법으로 뒤끝 기능을 호출할 수 있습니다.  
뒤끝 기능을 호출하면 그 응답을 기다리는 만큼 뒤끝펑션의 응답 시간이 늘어납니다. 자세한 내용은 [응답 시간](/sdk-docs/function/basic/respone-time) 문서를 참고해 주세요.  

| 하고 싶은 일 | 문서 |
| --- | --- |
| 함수를 호출한 사용자 확인 | [호출한 사용자 확인하기](/sdk-docs/function/request-response/caller) |
| 인앱 결제 영수증 검증 | [영수증 검증](/sdk-docs/function/backnd-features/receipt-check/validate-receipt) |
| 뒤끝 데이터베이스 읽기·쓰기 | [뒤끝 데이터베이스 사용](/sdk-docs/function/backnd-features/database) |

## 동기 방식으로 호출하기

`Backend.GameData`, `Backend.Receipt`, `Backend.BMember` 같은 뒤끝 기능은 함수 안에서 **동기 방식**으로 호출합니다. 콜백을 받는 비동기 함수는 사용하지 않습니다.  
함수를 `async Task<Stream>`으로 작성한 경우에도 뒤끝 기능은 동기 방식으로 호출합니다.  
뒤끝 데이터베이스(`BACKND.Database.Client`)는 예외입니다. `Task`를 반환하므로 `await`로 호출합니다.  

## 뒤끝베이스 버전

뒤끝펑션 1.1.1에 포함된 SDK는 뒤끝베이스 5.18.17을 기준으로 만들어졌습니다.  
5.18.17보다 높은 버전에서 추가된 함수는 사용하지 못할 수 있습니다.  

## 뒤끝베이스와 차이점

뒤끝펑션에서 호출하는 뒤끝 기능은 뒤끝베이스에서 제공하는 기능과 아래와 같이 일부 다릅니다.  

| 기능                         | 뒤끝베이스와 차이점                                              |
| :--------------------------- | :--------------------------------------------------------------- |
| 게임 유저                    | 인증(로그인, 회원가입 등) 기능을 제공하지 않습니다.              |
| 영수증 검증 / 게임 캐시 관리 | `ValidateReceipt`는 스토어 타입을 직접 지정해야 합니다. 이전 API의 구글 영수증 검증은 토큰 값을 다루는 방법이 일부 다릅니다. [영수증 검증](/sdk-docs/function/backnd-features/receipt-check/validate-receipt) 문서를 참고해 주세요. |

### 길드 기능

뒤끝펑션에서는 아래 길드 기능만 사용할 수 있습니다.  

- 길드 리스트 조회
- 내 길드 정보 조회
- 내 길드 굿즈 조회
- 메타 정보 수정
- 재화 기부
- 재화 사용
  > 재화 사용은 길드 마스터만 할 수 있습니다.  

::::danger 뒤끝펑션에서 지원하지 않는 기능
뒤끝펑션에서는 뒤끝베이스의 일부 기능이 동작하지 않습니다.  
동작하지 않아 제외한 기능은 아래와 같습니다.  
이 밖에도 정상적으로 동작하지 않는 기능이 있을 수 있으므로, 사용하기 전에 동작을 확인해 주세요.  

- 실시간 알림
- 클라우드 세이브
- [유저 데이터] 갱신/연산/삭제 함수 중 `UpdateMyData`처럼 **이름에 My가 들어간 함수**
- CDN 차트의 로컬 저장/로드 기능

:::caution 일부만 동작하는 기능
**[유저 데이터] 트랜잭션 함수 중 이름에 My가 들어간 함수는 사용할 수 없습니다.**  

- 유저 데이터 - 트랜잭션 쓰기
  - AddInsert : 사용 가능
  - AddUpdateOtherData : 수정하려는 데이터가 자신의 데이터일 때만 사용 가능
  - AddDeleteOtherData : 사용 불가

- 유저 데이터 - 트랜잭션 읽기
  - AddGetAllLatestData : 사용 가능
  - AddGetOtherLatestData : 조회하려는 데이터가 자신의 데이터일 때만 사용 가능
  - AddGetOtherData : 조회하려는 데이터가 자신의 데이터일 때만 사용 가능

:::

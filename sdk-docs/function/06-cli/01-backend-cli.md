# Backend CLI

개발사에서 생성한 뒤끝펑션 프로젝트를 빌드, 배포, 삭제하기 위해서는 Backend CLI를 사용해야 합니다.  

## 사용법

cmd에서 아래와 같은 방법으로 Backend CLI를 호출하여 사용할 수 있습니다.  

- backend \[명령어]
- backend \[명령어] \[하위 명령어]
- backend \[명령어] \[하위 명령어 1] \[하위 명령어 2]

## 명령어

Backend CLI에서는 아래의 명령어를 사용할 수 있습니다.  

| 명령어 | 설명                                              |
| :----- | :------------------------------------------------ |
| config | Backend CLI를 사용하기 위한 계정 및 프로젝트 설정 |
| build  | 뒤끝펑션 프로젝트 빌드                            |
| deploy | 뒤끝펑션 프로젝트를 서버로 배포                   |
| delete | 서버에 배포된 뒤끝펑션 프로젝트를 삭제            |
| help   | 도움말                                            |

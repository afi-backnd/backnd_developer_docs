# Visual Studio Code 프로젝트 생성

## Visual Studio Code에서 뒤끝펑션 Extension을 이용하여 새 프로젝트 생성하기

### 1. 마켓 플레이스에서 BackendFunction Extension 설치하기

vscode 내 확장 - 마켓 플레이스 검색에서 BackenFunction을 검색한 후, 검색된 BackendFunction을 Install 합니다.  
혹은 vscode 용 [마켓 플레이스 웹페이지](https://marketplace.visualstudio.com/items?itemName=AFI.backendfunction)에서 검색 후, Install 할 수 있습니다.  

![image](/img/docs/guide/function/intro/install-extension.png)

---
####
2. 명령 팔레트에서 BackendFunction : Create 호출

Extension 설치 후, 명령 팔레트(Ctrl + Shift + P)을 열고 입력창에 BackendFunction: Create를 입력합니다.  

![image](https://developer.thebackend.io/static/img/bfunc/createforvscode/2.PNG)

---
####
3. 프로젝트 폴더를 생성할 폴더를 선택합니다

![image](https://developer.thebackend.io/static/img/bfunc/osx/vscode/create/mac-create-1.png)

---
####
4. 생성할 폴더의 이름을 입력합니다

폴더의 이름이 **공백이거나 선택한 폴더 내 같은 이름이 있을 경우**에는 에러가 발생합니다.  

![image](https://developer.thebackend.io/static/img/bfunc/createforvscode/4.PNG)

---
####
5. 생성 완료

이후 템플릿 파일 생성 시, 새로운 VSCode 새 창이 열리며, 해당 프로젝트로 이동합니다.  
해당 프로젝트는 2~3번 작업으로 지정한 파일 경로로 생성됩니다.  

![image](https://developer.thebackend.io/static/img/bfunc/osx/vscode/create/mac-create-2.png)

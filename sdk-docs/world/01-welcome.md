# 월드

월드는 지속형 게임 서버를 쉽고 빠르게 개발할 수 있도록 지원하는 종합 서버 솔루션입니다. 복잡한 서버 인프라 구축과 네트워크 최적화에 대한 부담 없이, 게임 개발에만 집중할 수 있습니다. 실시간 동기화, 서버 확장, 데이터 관리와 같은 까다로운 문제들을 자동으로 처리하여 개발 시간과 비용을 크게 절감할 수 있습니다.
  
서버 구축부터 운영까지 필요한 모든 기능을 제공하여, 개발팀은 게임의 핵심 로직과 콘텐츠 개발에 리소스를 집중할 수 있습니다. 자동화된 스케일링과 최적화된 네트워크 시스템으로 게임의 성장에 따른 기술적 부담을 최소화하며, 안정적인 서비스 구축을 가능하게 합니다.

:::tip 시작하기
[설치 가이드](/sdk-docs/worlds/getting-started/install)를 통해 Unity용 월드 SDK를 설치하고 첫 번째 멀티플레이어 게임을 만들어보세요.
:::

## 주요 기능

### 네트워킹 & 동기화
네트워크 자동 복구와 실시간 상태 동기화
- 초저지연 네트워크 지원
- 실시간 상태 동기화
- 자동 장애 복구 시스템

### 게임 플레이
매끄러운 게임 경험을 위한 네트워크 보정
- 부드러운 움직임 보장
- 지연 보상 처리
- 충돌 해결 시스템

### 서버 인프라
트래픽에 따른 자동 스케일링과 분산 처리
- 자동 용량 조절 기능
- 비용 최적화 시스템
- 글로벌 분산 시스템

### 데이터 테이블
중앙화된 게임 데이터 관리 시스템
- 게임 콘텐츠 데이터 관리
- 스프레드시트 형식 제공
- CDN 자동 배포

### 리모트 컨피그
실시간 게임 데이터 값 관리 시스템
- 서버 재배포 없는 실시간 업데이트
- 게임 밸런스 즉시 조정
- 설정값 실시간 적용

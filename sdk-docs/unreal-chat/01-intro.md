# 시작하기

:::info
Unreal SDK는 커스텀 인증만 사용이 가능 합니다. [커스텀 인증](/sdk-docs/unreal-chat/custom-auth)를 참고하세요.
:::

<br/>

Unreal SDK를 통해 실시간 채팅 기능을 Unreal 프로젝트에 빠르게 추가할 수 있어요.

:::tip 가장 빠르게 채팅 기능을 테스트하고 싶다면?
뒤끝에서 제공하는 [예제 프로젝트](/sdk-docs/unreal-chat/example-game)를 활용해서 바로 시작해보세요!
이미 완성된 UI와 함께 실시간 채팅이 작동하는 과정을 직접 확인하고, 필요한 부분만 가져다 쓸 수 있습니다.
:::

## 유저 닉네임 설정

채팅을 사용하려면 유저의 닉네임을 반드시 설정해야 합니다. 닉네임은 커스텀 인증 서버가 응답한 `nickname`이 사용됩니다. 채팅 서버에 접속한 뒤 닉네임을 변경하는 방법은 [유저](/sdk-docs/unreal-chat/user#닉네임-변경-순서) 문서를 참고하세요.

## 요구사항

Unreal SDK의 최소 요구 사항은 다음과 같습니다.

- Unreal Engine 5.3  

플랫폼별 제한 사양과 권장 사양은 [설치 및 환경 구성](/sdk-docs/unreal-chat/install#지원-플랫폼-및-요구-사양) 문서에서 확인하세요.

:::info
Unreal Engine 4.27 도 지원을 하고 있습니다. 따로 채팅 SDK가 준비 되어 있습니다. 사용하시는 Unreal Engine 버전을 확인 하여 맞는 채팅 SDK를 사용 해 주시길 바랍니다.
:::

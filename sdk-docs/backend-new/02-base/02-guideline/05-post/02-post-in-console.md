# 콘솔에서 우편 발송하기

## 1. 콘솔에서 우편 발송

뒤끝 콘솔 `뒤끝 베이스 > 우편 관리`에서 **우편 등록** 버튼을 클릭합니다.  

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/post/post-console-create.png" />

즉시 발송되는 우편을 생성합니다.  

| 구분      | 설정 값      |
| :-------- | :----------- |
| 발송일    | **즉시발송** |
| 만료기간  | 원하는 값    |
| 제목      | 원하는 값    |
| 내용      | 원하는 값    |
| 발송인    | 원하는 값    |
| 푸시 발송 | **빈칸**     |

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/post/post-console-detail1.png" />

하단에 있는 **아이템 등록**을 클릭하여 지급할 아이템을 선택합니다.  

| 구분   | 설정 값     |
| :----- | :---------- |
| 차트   | 아이템 차트 |
| 아이템 | 원하는 값   |
| 수량   | 원하는 값   |

만약 지급 아이템을 선택할 수 없는 경우에는 **우편 기능 사용이 가능한 아이템 차트**가 존재하지 않아 발생할 수 있습니다.  
이러한 경우에는 [Step 1. 사전 준비](/sdk-docs/backend/base/guideline/post/before)를 참고하여 우편 이용이 가능한 아이템 차트를 생성해주세요.  

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/post/post-console-detail2.png" />

이후 발송 대상을 **전체**로 설정하고 확인을 눌러 우편을 생성합니다.  

| 구분      | 설정 값  |
| :-------- | :------- |
| 발송 대상 | **전체** |

<img src="https://developer.thebackend.io/static/img/outline/manual/beginner/post/post-console-detail3.png" />

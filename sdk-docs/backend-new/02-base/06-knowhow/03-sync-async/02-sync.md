# Task 함수
동기 함수란 요청 시점에서 요청 시점에서 await를 통해 결과를 받을 때까지 대기가 가능한 함수입니다.  
함수를 호출 후, await 키워드를 추가하면 리턴 값이 반환될 때까지 메인 스레드 멈춤없이 대기가 가능합니다.  

Callback 함수와는 다르게 순차적으로 함수가 호출되어 순서가 섞일 가능성이 없으며, 작업 도중 다른 스레드에 의해 오류가 발생할 경우가 없기 때문에 확실한 결과를 제공합니다.  

## 뒤끝 Task 함수 사용 시 주의사항
게임 정보나 게임테이블, 랭킹 정보 등의 큰 데이터를 불러오는 함수를 호출할 경우, 처리하는 데이터의 양이 많아 응답을 받기까지 오래 걸릴 수 있습니다.  
순차 처리가 필요 없는 경우라면 굳이 await로 대기할 필요는 없습니다. 결과값을 받은 이후에 추가 처리가 필요한 경우에만 await를 사용하면 됩니다.  
내부에서는 UnityWebRequest를 사용하여 통신을 하기때문에 메인스레드가 아닌 곳에서 호출하면 오동작 가능성이 있습니다.  

## Task 함수를 호출하는 상황
* 대부분의 상황에서 함수 호출 시 사용이 추천됩니다.  
* 결과를 받을 때까지 확실하게 대기해야 하는 경우
* 함수를 순서에 맞게 처리해야 하는 경우에 추천됩니다.  

## Task 함수를 호출하면 안 되는 상황
* async/await 를 사용할 수 없는 경우

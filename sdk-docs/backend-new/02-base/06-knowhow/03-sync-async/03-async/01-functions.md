# Callback 함수
Callback 함수는 Task처럼 비동기로 동작하지만 결과값을 기다리지 않는 함수입니다.  
호출한 스레드에서 해당 함수 호출에 대한 결과를 기다리지 않고 바로 다음 작업을 수행할 수 있습니다.  

## Callback 함수 사용 시 주의사항
* 호출 순서에 따른 순서 보장이 되지 않습니다.  
* 게임 정보의 동일한 row 수정과 같은 작업을 수행하면 최종적 읽기 일관성이 보장이 안되어 일부 요청이 실패할 수 있습니다.  
* 한 번에 여러 개의 Callback 함수를 요청하는 경우 8개 이하로 요청하는 것이 권장됩니다.  

## Callback 함수를 호출하는 상황
* 함수 호출 순서 간 순서 보장이 필요하지 않을 때
* 다른 외부 함수의 콜백내에서 뒤끝 함수를 실행해야 하는 경우
* 호출만 하고 결과를 받는 시점을 고려하지 않아도 되는 경우

## Callback 함수를 호출하면 안 되는 상황
* 한 번에 여러 개의 Callback 함수를 요청하고 요청한 순서 간의 순서 보장이 필요할 때
* 한 번에 여러 개의 Callback 함수를 요청하고, 이때 동일한 데이터의 수정 작업을 수행할 때
  * 게임 정보 수정 시 테이블 내 동일한 row 수정 요청을 한 번에 여러 개 보낸 경우 요청 중 1개만 성공하게 됩니다.  
  * 길드 메타 데이터/굿즈 수정, 실시간 랭킹 갱신 등의 작업이 모두 이에 해당됩니다.

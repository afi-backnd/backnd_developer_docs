# 뒤끝매치
뒤끝매치는 게임을 이용하는 유저들을 규칙에 따라 매칭 시켜준 후 실시간으로 게임할 수 있는 환경을 제공하는 서비스입니다.  

뒤끝매치에서는 아래와 같은 기능을 제공합니다.  
- 매칭 조건 / 유형에 따라 유저들을 매칭
- 매칭된 유저들이 실시간으로 게임할 수 있는 환경을 제공
- 게임 종료 후 결과를 종합하여 서버에 저장하고, 게임 결과에 따라 유저들의 점수를 증감시킴  
- 뒤끝매치는 별도의 추가 요금 청구 없이 모든 기능을 이용할 수 있습니다.

## 매칭 조건
| 매칭 조건 | Description |
| --- | --- |
| **랜덤 매칭** | 규칙 없이 매칭을 신청하는 모든 유저를 무작위로 매칭 |
| **포인트 매칭** | 개발자가 직접 설정한 포인트를 기반으로 유저를 매칭 |
| **MMR 매칭** | Elo 레이팅 규칙에 따라 MMR을 기반으로 유저를 매칭 |

## 매칭 유형
| 매칭 유형 | Description |
| --- | --- |
| **1:1** | 1:1 게임을 지원합니다. |
| **팀전** | 2:2, 3:3, 4:4, 5:5 게임까지 지원합니다. |
| **개인전** | 최소 3명에서 최대 10명까지 지원합니다. <br />개인전 게임의 경우 배틀로얄 방식을 지원합니다. |

## 실시간 게임 환경
뒤끝매치에서는 매칭된 유저들이 실시간으로 메시지를 주고받을 수 있는 환경을 제공합니다.  
- 매칭된 유저들 간의 실시간 브로드캐스팅 지원
- 게임 시작, 종료 및 결과 처리에 대한 프로세스 제공
- 게임 진행 중 접속이 끊긴 유저에 대한 재접속 기능 제공

## 레이턴시
뒤끝매치 실시간 게임 환경에서는 평균적으로 50ms 이하의 레이턴시가 측정됩니다.  
측정하는 기기, 통신환경, 통신 상황에 따라 다르게 측정될 수 있습니다.

- 안정적인 클라우드 인프라를 제공해, 서버 관리 없이 콘텐츠 개발에만 집중할 수 있어요.

## 월드 서버

월드 서버는 대규모 멀티플레이어 환경에서 데이터를 실시간으로 동기화하도록 설계된 서버입니다.  
다양한 기능을 활용하여 게임의 서버 환경을 유연하고 효율적으로 관리할 수 있습니다.

### 주요 기능

### 1. 시뮬레이션 서버
- Linux 빌드 파일을 업로드하여 사용자 정의 서버 로직을 월드 서버에 적용할 수 있습니다.
- 빌드 파일 업로드 방법은 아래 가이드를 참고하세요:
[빌드 파일 업로드 방법](/sdk-docs/worlds/welcome)

### 2. 리모트 컨피그
- 실시간으로 반영 가능한 환경 변수를 설정하여 동적으로 서버 환경을 관리할 수 있습니다.
- 빠르게 변수값을 변경하고 월드 서버에 즉시 반영하여 플레이어 경험을 개선하세요.

### 3. 데이터 테이블 연동
- 데이터 테이블을 연결하여 월드 서버 시작 시 불러올 초기 데이터를 설정할 수 있습니다.
- 게임에 필요한 설정값이나 초기 데이터를 손쉽게 관리하고 유지할 수 있습니다.

## 데이터 테이블
- 월드 서버가 시작될 때 필요한 초기 데이터를 데이터 테이블로 관리하세요.
- 데이터의 효율적 관리와 빠른 업데이트가 가능합니다.
- 몬스터 정보, 아이템 정보, 맵 정보, 퀘스트 정보 등 다양한 데이터를 테이블 형태로 저장 및 관리할 수 있습니다.

## 유저 인증
안전하고 신뢰할 수 있는 뒤끝의 인증 서버를 통해 플레이어 인증을 간편하게 처리하세요.

# 데이터베이스

데이터베이스는 **게임 내 모든 종류의 데이터를 구조적으로 저장하고 관리하는 백엔드 스토리지**입니다.  
개인의 유저 데이터부터 여러 유저가 동시에 변경하는 공용 데이터까지 한 곳에서 다룰 수 있습니다.

관련 콘솔 가이드 : [데이터베이스란?](/guide/console-guide/database/introduction)  
관련 SDK 개발자 문서 : [데이터베이스 시작하기](/sdk-docs/database/intro)

## 어떤 데이터를 다루나요

| 구분 | 설명 | 예시 |
| --- | --- | --- |
| **유저 테이블** | 각 유저에게 귀속되는 데이터 | 레벨, 보유 재화, 인벤토리 |
| **자유 테이블** | 여러 유저가 함께 읽고 쓰는 공용 데이터 | 보스 체력, 점령 지역, 서버 이벤트 |

기존 베이스의 **게임 정보**는 유저 귀속 데이터만, **차트**는 조회 전용 참조 데이터만 다룰 수 있었습니다.  
데이터베이스는 이 둘을 모두 포괄하면서, 공용 상태를 변경해야 하는 콘텐츠까지 구현할 수 있도록 설계되었습니다.


## 주요 특징

### 1. 유저 데이터와 공용 데이터를 함께 관리

단일 유저의 상태뿐 아니라 서버 전체가 공유하는 데이터까지 하나의 저장소에서 다룹니다.  
영토 점령, 길드 보스, 비동기 PvP처럼 **공용 상태를 기반으로 하는 콘텐츠**를 구현할 수 있습니다.

### 2. 직관적인 테이블 · 컬럼 스키마 관리

- NoSQL 기반의 유연한 스키마
- 테이블 타입 구분(유저 테이블 / 자유 테이블)
- 컬럼 타입, 사용자 정의 인덱스, 복합 인덱스 구성
- 백업 주기 설정 및 복원

### 3. LINQ 스타일의 유연한 쿼리

`Where`, `First`, `ToList`, `Add`, `Transaction` 등 개발자에게 익숙한 문법으로 데이터를 다룹니다.  
조건 검색, 정렬, 트랜잭션까지 지원하므로 복잡한 게임 로직도 쿼리로 표현할 수 있습니다.

### 4. SQL 기반 쿼리 에디터

콘솔에서 직접 데이터를 조회하고 수정할 수 있어, 운영 중 데이터 확인과 수정이 편리합니다.

## 콘솔에서 할 수 있는 일

| 메뉴 | 기능 |
| --- | --- |
| **테이블** | 테이블 생성, 컬럼 구성, 데이터 조회 · 삽입 · 수정 · 삭제, CSV 임포트 |
| **쿼리 에디터** | SQL로 데이터 직접 조회 및 수정 |
| **설정** | DB UUID · 리전 확인, 인덱스 설정, 백업 주기 및 복원, 비활성화 |
| **요금제 & 사용량** | 제공량 · 초과량 확인, 요금제 변경, 월별 사용량 조회 |

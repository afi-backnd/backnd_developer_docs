# 친구 기능
뒤끝은 게임 유저 간의 친구 기능을 제공합니다.  

<ConsoleLinkButton text="친구 설정 바로가기" menu="settingSocial" feature="소셜 설정" title="친구 기능" />

관련 콘솔 가이드 : [프로젝트 설정 - 소셜 - 소셜 설정](/guide/console-guide/server-setting/social)  
관련 SDK 개발자 문서 : [친구 기능 - 친구 목록 조회하기](/sdk-docs/backend/base/friend/list-friends)

## 친구 관리
- 유저 간에는 친구 요청, 수락 및  거절할 수 있습니다.  
- 콘솔 내에서는 친구 최대 수를 설정할 수 있습니다.  

## 친구 기능
- 친구를 맺은 유저는 닉네임과 키값(inDate)을 쉽게 확인할 수 있습니다.  

## 실시간 알림
실시간 알림을 통해 다음과 같은 알림을 받을 수 있습니다.  
- 친구 요청 도착
- 친구 요청 수락
- 친구 요청 거절
- 친구 게임 접속
- 친구 게임 종료

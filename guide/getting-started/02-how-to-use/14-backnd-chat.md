# 채팅

인게임 채팅을 손쉽게 구현하고 효과적으로 관리하세요.  
유저는 실시간으로 메시지를 주고 받을 수 있고,  
운영자는 비속어 필터링, 신고 확인 및 차단, 도배 방지, 관리자 메시지 전송 등의 운영 기능을 사용할 수 있습니다.

## 채널
유저는 채널 안에서 실시간으로 메시지를 주고 받습니다. 뒤끝에서는 게임에 특화된 2개의 채널 타입을 제공합니다.

|구분|프라이빗 채널|오픈 채널|
|---|---|---|
|예시|🛡️길드 채널, ⚔️매치 채널|🔊언어별 채널, 🌎국가별 채널|
|인원|최대 인원이 설정된 값으로 고정됩니다.|유동적으로 변화하는 인원에 따라서 채널이 자동으로 확장됩니다. 확장된 채널은 1, 2, 3, ... 순서대로 채널 번호가 부여됩니다.|
|채널 생성 및 입장|유저가 채널을 생성할 수 있고, 비밀번호를 설정할 수 있습니다|채팅 서버에 접속할 때 자동으로 채널에 입장합니다. FALLBACK이 지정된 경우에 입장해야 하는 특정 채널이 없는 경우 자동으로 FALLBACK 채널에 입장합니다.|

이외에 뒤끝에서 자동으로 관리되는 예약어 채널을 제공합니다. 귓속말, (베이스의 길드 기능과 연동된) 길드별 채널, (베이스의 유저 프로퍼티와 연동된) 언어별 채널, 국가별 채널, 국가코드별 채널을 사용할 수 있습니다.

## 운영자 기능
- **관리자 메시지**: 게임에 접속하지 않더라도 콘솔에서 실시간으로 관리자 메시지를 채널에 전송할 수 있습니다.
- **비속어 필터**: 자동으로 필터링할 비속어 목록을 언어별로 설정할 수 있습니다.
- **신고와 차단**: 신고 사유, 신고 횟수 제한, 신고 기간 제한을 설정할 수 있고, 접수된 신고 내용을 확인하고 유저를 차단할 수 있습니다.
- **도배**: 도배를 할 수 없도록 예방하거나, 도배를 했을 경우 패널티를 적용하는 방법 중에서 선택하여 설정할 수 있습니다.

## 번역
실시간 자동 번역과 온디맨드 번역 기능을 제공합니다.
- 자동 번역: 채팅 서버에서 자동으로 번역한 결과를 채널에 전송합니다.
- 온디맨드 번역: 이미 받은 채팅 메세지에 대해서 유저가 원할 때 번역을 요청합니다.



## 커스텀 인증
이미 인증 서버와 유저 DB를 구축하고 계신 팀이라면, 뒤끝에서 제공하는 인증 서버를 사용하는 대신, **자체 유저 인증 서버를 채팅 서버와 연결**해서 사용할 수 있습니다. 

## Platform API
채팅 서버의 데이터를 직접 관리할 수 있도록 라이브옵스 기능을 API 형태로 제공합니다. **별도의 운영 대시보드를 구축한 경우, Platform API를 직접 연결**하여 보다 효과적으로 게임을 운영할 수 있습니다.

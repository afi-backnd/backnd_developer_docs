# DB 이용이 발생하는 기능

## 베이스

뒤끝 베이스 기능의 경우 **기능의 종류 관계없이 모든 기능을 호출 시 유저의 인증을 실시하고, 이때 0.5 ~ 2 읽기 처리량, 0.5 ~ 2 쓰기 처리량이 발생**합니다.  
즉 DB 이용이 발생하는 경우 **해당 기능의 DB 이용(읽기, 쓰기 처리량) + 유저 인증 처리량이 발생**하게 됩니다.  
> 서버 시간 조회, 서버 상태 조회, 서버 버전 조회 이 3가지 함수의 경우 유저 인증으로 인한  읽기, 쓰기 처리량이 발생하지 않습니다.  

| 기능 | 설명 |
| --- | --- |
| 게임 운영 | 공지사항, 이벤트, 정책기능을 이용 시 DB 이용이 발생합니다. |
| 1대1 문의 | 1대1 문의 기능을 이용 시 DB 이용이 발생합니다. |
| 게임 정보 | 게임 정보를 삽입/수정/조회/삭제 시 이용한 데이터의 크기만큼 DB 이용이 발생합니다. |
| 클라우드 세이브 | 유저 인증 과정에서 발생하는 DB 이용을 제외하고, DB 이용이 발생하지 않습니다. |
| 게임 유저 | 게임 유저 관리에 존재하는 기능을 이용 시 DB 이용이 발생합니다.|
| 리더보드 | 리,더보드 기능을 이용 시 DB 이용이 발생합니다.<br />1회 갱신, 조회의 DB 이용은 유저 수와 관계없이 거의 동일합니다.<br />리더보드 초기화 시 컬럼 초기화 기능을 사용할 경우 리더보드에 참여한 유저의 수만큼 DB 이용이 발생합니다. |
| (구) 리더보드 | (SDK 5.4.0 미만) 리더보드 기능을 이용 시 DB 이용이 발생합니다.<br />유저가 많아질 경우 리더보드 갱신 시 유저의 수에 비례하게 DB 이용이 증가할 수 있습니다. |
| (구) 실시간 리더보드 | (SDK 5.4.0 미만) 실시간 리더보드 기능을 이용 시 DB 이용이 발생합니다. <br /> 1회 갱신, 조회의 DB 이용은 유저 수와 관계없이 거의 동일합니다. |
| 쿠폰 관리 | 유저 인증 과정에서 발생하는 DB 이용을 제외하고, DB 이용이 발생하지 않습니다. |
| 푸시 설정 | 푸시 토큰을 저장/삭제 시 DB 이용이 발생합니다. |
| 게임 로그 | 게임 로그v1 저장/조회 시 DB 이용이 발생합니다.<br />게임 로그v2 저장/조회 시 유저 인증 과정에서 발생하는 DB 이용을 제외하고, DB 이용이 발생하지 않습니다. |
| 차트 관리 | 유저 인증 과정에서 발생하는 DB 이용을 제외하고, DB 이용이 발생하지 않습니다.<br />차트의 데이터 크기와 DB 이용량은 무관합니다. |
| 확률 관리 | 유저 인증 과정에서 발생하는 DB 이용을 제외하고, DB 이용이 발생하지 않습니다.<br />확률 차트의 데이터 크기와 DB 이용량은 무관합니다. |
| 유저 검색 | 유저 검색 시 DB 이용이 발생합니다. |
| 우편 기능 | 우편 기능 사용 시 DB 이용이 발생합니다. |
| 쪽지 기능 | 쪽지 기능 사용 시 DB 이용이 발생합니다. |
| 길드 기능 | 길드 기능 사용 시 DB 이용이 발생합니다. |
| 실시간 알림 | 실시간 알림은 DB 이용이 발생하지 않습니다. |
| 뒤끝펑션 | 유저 인증 과정에서 발생하는 DB 이용을 제외하고, DB 이용이 발생하지 않습니다.<br />다만 뒤끝펑션 내에서 뒤끝베이스의 기능 호출 시 DB 이용이 발생할 수 있습니다.|

## 채팅

| 기능 | 설명 |
| --- | --- |
| 채팅 서버 접속 | 유저 인증 과정에서 베이스 DB 이용이 발생합니다. (커스텀 인증 사용 시 미발생) |
| 유저 차단/해제 | 유저 인증 과정에서 베이스 DB 이용이 발생합니다. (커스텀 인증 사용 시 미발생) |
| 채팅, 귓속말 | 메시지 송/수신 시 채팅 DB 이용이 발생합니다. |
| 유저 신고 | 유저 신고 시 채팅 DB 이용이 발생합니다. |
| 번역 | 번역 과정에서 채팅 DB 이용이 발생합니다. |
| DB 이용 외 | 채팅의 모든 호출/콜백에는 트래픽 이용이 발생합니다. |

## 뒤끝매치

| 기능 | 설명 |
| --- | --- |
| 매칭 카드 리스트 조회 | 유저 인증 및 매칭 카드 리스트 조회 과정에서 DB 이용이 발생합니다.|
| 매치 / 인게임 서버 접속 | 유저 인증 과정에서 DB 이용이 발생합니다.  |
| 매치 / 인게임 서버에서 데이터 송수신 | DB 이용이 발생하지 않습니다. |
| 매치 결과 종합 | 결과 저장 과정에서 DB 이용이 발생합니다. |
| 매칭 결과 조회 | 결과 조회 과정에서 DB 이용이 발생합니다. |

## 콘솔
콘솔에서 데이터를 조회할 때 SDK와 동일하게 DB 요금이 발생합니다.

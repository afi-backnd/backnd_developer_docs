# 설정
:::warning 채팅(신버전) 출시로 뒤끝챗 지원이 종료되었습니다.  
뒤끝챗은 모든 업데이트와 지원이 종료되었습니다.  
기존 뒤끝챗을 활성화한 프로젝트에 한하여 25년 2월 28일까지만 이용 가능합니다.  

25년 3월 1일부터 뒤끝챗의 서비스가 종료되어 기존 뒤끝챗을 이용하던 프로젝트의 경우도 더 이상 이용이 불가합니다.  
새롭게 출시된 <a href="https://docs.thebackend.io/sdk-docs/chat/intro">**채팅**</a>을 이용해 주세요.
:::

## 비속어 필터링
비속어 필터링은 채팅 사용 시, 해당 단어들을 **별 표시(*)**로 치환해주며, 콘솔에서는 필터링 단어들을 추가하거나 수정, 삭제할 수 있습니다.  
- 표준 비속어 필터링 리스트가 뒤끝챗 활성화 시 기본 제공됩니다.  
- 단어는 쉼표(,)로 구분하며 공백을 허용하지 않습니다.  
- 영문의 경우 대소문자를 구분하지 않습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--설정.png" />

### 비속어 추가/수정/삭제
비속어 필터링 입력창에 비속어를 추가 또는 삭제할 수 있습니다.  
<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--설정---비속어-필터링.png" />

## 자동 접속 종료
선택한 시간 동안 모든 채널에서 채팅 입력이 없는 게임 유저는 자동으로 채팅 서버와의 접속이 종료됩니다.  
- 디폴트는 **사용 안 함**이며 **15분/30분/1시간/3시간/6시간** 중 선택이 가능합니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--설정---자동-접속-종료.png" />

## 도배 방지
도배 방지는 설정한 시간 내에 반복적으로 채팅 메시지를 입력할 경우 해당 유저의 채팅을 금지시키는 기능입니다.

# 채널 관리
:::warning 채팅(신버전) 출시로 뒤끝챗 지원이 종료되었습니다.  
뒤끝챗은 모든 업데이트와 지원이 종료되었습니다.  
기존 뒤끝챗을 활성화한 프로젝트에 한하여 25년 2월 28일까지만 이용 가능합니다.  

25년 3월 1일부터 뒤끝챗의 서비스가 종료되어 기존 뒤끝챗을 이용하던 프로젝트의 경우도 더 이상 이용이 불가합니다.  
새롭게 출시된 <a href="https://docs.thebackend.io/sdk-docs/chat/intro">**채팅**</a>을 이용해 주세요.
:::

**채널 관리**에서는 현재 뒤끝챗을 이용하고 있는 유저들의 채널들을 확인할 수 있습니다.  
클라이언트에서의 기능은 [개발자 문서 - 뒤끝챗](/sdk-docs/backend/chat/start-up)을 참고해 주세요.  
- 새로 고침 버튼 클릭 시, 선택된 그룹의 채널 리스트를 다시 받아옵니다.  
- 생성된 채널은 자동으로 삭제되지 않으며, 직접 수동으로 삭제해야 합니다.  
- 채팅 그룹의 설정이 자동 생성일 경우, 현재 접속 유저 수가 모든 채널의 최대 유저 수 합의 80% 이상일 때 채널이 생성됩니다.  
-  일반 채널 자동 생성 시 **프로젝트 이름**, 길드 채널 자동 생성 시 **길드 이름의 채널**이 생성됩니다.  
> SDK 5.2.0 미만 버전에서는 채널당 인원은 최대 100명입니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-관리.png" />

## 채팅 그룹 선택
상단의 **셀렉트 박스**에서 채팅 그룹을 선택할 수 있습니다.  
* 최근 생성된 채널 그룹이 제일 상단에 위치하게 됩니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-관리---채팅-그룹-선택.png" />

## 채널 생성
페이지 상단의 명령 버튼 중 **채널 생성** 버튼을 클릭해 새로운 채널을 만들 수 있습니다.  
* 채팅 그룹의 분류가 **길드**이거나 **채널 자동 생성이 사용**으로 되어있을 경우에는 채널 만들기가 불가합니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-관리---채널-생성.png" />

## 채널명 수정
화면 우측의 **수정** 버튼을 클릭해 채널명을 수정할 수 있습니다.  
* 채팅 그룹의 분류가 **길드**이거나 **채널 자동 생성이 사용**으로 되어있을 경우에는 채널명 수정이 불가합니다.  
<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-관리---채널-수정.png" />

## 채널 삭제하기
해당 채널을 삭제합니다.  
채널을 삭제하면 더 이상 해당 채널로 접속할 수 없으며, 기존에 접속된 유저들은 연결이 유지됩니다.  
* 채팅 그룹의 분류가 **길드**이거나 **채널 자동 생성이 사용**으로 되어있을 경우에는 채널 삭제가 불가합니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-관리---채널-삭제.png" />

# 공지 관리
:::warning 채팅(신버전) 출시로 뒤끝챗 지원이 종료되었습니다.  
뒤끝챗은 모든 업데이트와 지원이 종료되었습니다.  
기존 뒤끝챗을 활성화한 프로젝트에 한하여 25년 2월 28일까지만 이용 가능합니다.  

25년 3월 1일부터 뒤끝챗의 서비스가 종료되어 기존 뒤끝챗을 이용하던 프로젝트의 경우도 더 이상 이용이 불가합니다.  
새롭게 출시된 <a href="https://docs.thebackend.io/sdk-docs/chat/intro">**채팅**</a>을 이용해 주세요.
:::

**공지 관리**에서는 현재 채널에 접속 중인 모든 유저들에게 즉시 전체 채팅 메시지를 발송할 수 있습니다.  
공지 채팅은 차단이 불가능하며 비속어 필터링 처리에서 제외됩니다.  
클라이언트에서의 기능은 [개발자 문서 - 뒤끝챗](/sdk-docs/chat/intro)을 참고해 주세요.  

:::danger 주의
공지 받기, 보내기 기능은 Backend-4.5.0 이상 버전에서만 사용할 수 있습니다.  
운영자 등록은 자정(24:00)을 기준으로 업데이트 됩니다.  
:::

## 공지 발송
선택한 채널의 모든 유저에게 작성한 내용을 공지 메시지로 발송합니다.  

### 발송 채널
- 전체 채널 : 현재 존재하는 모든(일반+길드) 채널
- 일반 채널 : 현재 존재하는 모든 일반 채널
- 길드 채널 : 현재 존재하는 모든 길드 채널

### 발송 명
- 공지 메시지 발송 시 채팅 채널에 표시될 닉네임

### 발송 내용
- 공지로 발송할 채닝 내용을 입력하며, 최대 512byte까지 발송 가능합니다.  
- 별도의 입력 제한은 없지만 입력한 내용이 512byte 초과 시 초과되는 부분은 채팅에서 출력되지 않습니다.  
- 엔터키(줄 바꿈) 입력 부분은 무시되며 한 줄로 처리합니다.  

## 운영자 등록
회원번호나 닉네임을 입력하여 운영자로 등록할 수 있습니다.  
운영자로 등록된 유저는 인 게임 채팅에서 함수를 통해 전체 채팅을 보낼 수 있습니다.  
- 운영자 공지는 게임 내 모든 '일반 채널'에만 전달되며 길드 채널에는 전달되지 않습니다.  
(길드 채널만 사용하는 게임을 경우에는 뒤끝 콘솔의 공지 기능을 이용해 주시기 바랍니다.)
- 운영자로 등록된 계정의 전체 채팅(공지)은 차단/도배 방지/욕설 필터링에서 제외되며 유저들에게 예외 없이 무조건 보입니다.  
- 뒤끝챗 운영자는 프로젝트 당 최대 5명까지 등록 가능합니다.  
- 등록된 운영자는 목록 상단의 **삭제** 버튼을 클릭해 삭제할 수 있습니다.  
- 닉네임 중복 발생 시 먼저 검색되는 유저를 등록합니다.(회원번호 검색 권장)

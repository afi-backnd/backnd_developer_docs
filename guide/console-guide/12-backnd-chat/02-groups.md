# 채널 그룹 관리
:::warning 채팅(신버전) 출시로 뒤끝챗 지원이 종료되었습니다.  
뒤끝챗은 모든 업데이트와 지원이 종료되었습니다.  
기존 뒤끝챗을 활성화한 프로젝트에 한하여 25년 2월 28일까지만 이용 가능합니다.  

25년 3월 1일부터 뒤끝챗의 서비스가 종료되어 기존 뒤끝챗을 이용하던 프로젝트의 경우도 더 이상 이용이 불가합니다.  
새롭게 출시된 <a href="https://docs.thebackend.io/sdk-docs/chat/intro">**채팅**</a>을 이용해 주세요.
:::

**채널 그룹 관리**에서는 채팅 채널의 묶음인 채널 그룹을 생성하거나 수정, 삭제할 수 있습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-그룹-관리.png" />

## 채널 그룹 만들기
페이지 상단의 명령 버튼 중 **채널그룹 생성** 버튼을 클릭해 채널 그룹을 생성할 수 있습니다.  
채널 그룹은 **최대 10**개까지 생성 가능합니다.  
* 채널 그룹 분류를 길드로 선택할 경우 자동 채널 생성은 사용으로 고정됩니다.  
* 채널 그룹 분류를 길드로 선택할 경우 해당 채널 그룹에는 길드 채널만 생성됩니다.  
* 채널 자동 생성을 사용할 경우 현재 접속 유저 수가 모든 채널의 최대 유저 수 합의 80% 이상일 때 새로운 채널이 생성됩니다.  
* 채널 자동 생성을 미사용할 경우 미리 생성한 채널에만 접속할 수 있습니다.  
유저가 모두 채널에 접속하여 포화상태가 되어도 채널이 새로 생성되지 않습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-그룹-생성.png" />


## 채널 그룹 수정
채널 그룹 목록 우측의 **수정** 버튼을 클릭해 채널 그룹을 수정하실 수 있습니다.  
* 분류와 채널 자동 생성은 수정할 수 없으며 채널 그룹명만 수정 가능합니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-그룹-수정.png
" />


## 채널 그룹 삭제
삭제할 채널 그룹을 선택한 후 페이지 상단의 명령 버튼 중 **삭제** 버튼을 클릭해 채널 그룹을 삭제하실 수 있습니다.  
* 채널 그룹에 속한 채널이 존재할 경우에는 삭제가 불가능합니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/chat/뒤끝챗--채널-그룹-삭제.png
" />

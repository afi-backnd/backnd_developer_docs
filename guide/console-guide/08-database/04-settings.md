# 데이터베이스 설정

<!-- :::caution 출시 예정
데이터베이스는 **2026년 1월 출시 예정**입니다.
::: -->

데이터베이스의 기본 정보, 요금제 및 사용량, 인덱스, 백업 등을 관리합니다.

![데이터베이스 활성화 페이지](/img/docs/guide/database/database_007.png)

## UUID

- 데이터베이스를 식별하는 고유 ID입니다.
- SDK나 내부 도구 연동 시 사용될 수 있습니다.

## 리전

- 데이터베이스가 실제로 배치된 서버 위치입니다.
- 데이터베이스를 처음 생성할 때 자동으로 설정되며 생성 이후에는 변경할 수 없습니다.
- 현재 서울 리전을 지원하며, 향후 확대 예정입니다.

## 요금제 및 사용량

- 현재 사용중인 데이터베이스 요금제와 Read / Write / Storage 사용량을 확인할 수 있습니다.
- 각 항목은 현재 요금제의 무료 제공량 대비 얼마나 사용했는지 막대그래프로 표시됩니다.

## 인덱스

- 데이터 조회 성능 향상을 위해 컬럼 기반 인덱스를 설정할 수 있습니다.
- 데이터베이스 기준 **최대 10개**까지 생성할 수 있습니다. (모든 유저 테이블의 `user_uuid` 기본 인덱스는 제외)
- 한 인덱스는 **최대 4개 컬럼**을 묶어서 생성할 수 있습니다.
- JSON 타입 컬럼은 인덱스 생성 불가합니다.
- 인덱스는 각 테이블의 수정 페이지에서도 설정할 수 있습니다.

## 백업

백업 설정을 통해 데이터베이스 데이터를 정기적으로 자동 저장할 수 있습니다.

- 백업 주기: 24/12/6 시간 중 백업 주기를 선택합니다.
- 백업 실행 시각은 UTC 기준입니다. (KST=UTC+9)
- 보관 기간: 1일~14일까지 설정 가능합니다.
- 백업 기능은 요금제에 따라 선택할 수 있는 옵션이 다릅니다.

## 데이터베이스 비활성화

- 하단의 [비활성화하기] 버튼을 통해 데이터베이스를 삭제하고 서비스를 종료할 수 있습니다.
- 비활성화 시에는 프로젝트 이름과 비밀번호를 입력해 확인 절차를 거칩니다.
- 데이터베이스가 비활성화되면 저장된 모든 테이블 및 데이터가 삭제되며 복구할 수 없습니다.

# 관리자 우편

콘솔에서 관리자 우편을 보낼 수 있습니다.  
클라이언트에서의 기능은 [우편 기능](/sdk-docs/backend/base/post/difference-to-old#구버전-코드post)을 통해서 확인해 주세요.  

:::caution 주의
콘솔에서 우편을 보내기 위해서는 콘솔 > 차트 관리에 차트가 등록되어 있어야 합니다.  
차트를 생성할 시, 우편 사용 여부를 사용으로 해주셔야 우편 발송이 가능합니다.  
차트 등록에 대해서는 <a href="/guide/console-guide/backnd-base/chart" target="_blank">해당문서</a>를 참고해 주세요.  
:::

## 관리자 우편 발송

관리자는 콘솔에서 등록된 차트를 이용하여 해당 차트에 있는 아이템을 전체 유저 혹은 특정 유저에게 보낼 수 있습니다.  

- 발송 일시가 즉시 발송일 경우, 발송하기 버튼을 누른 시간으로 우편이 발송됩니다.  
- 예약 발송과 반복 발송은 30분 간격으로 시간을 선택할 수 있습니다.  
- 동일한 시간에 중복 우편 발송은 불가능합니다.  
- 푸시 발송을 입력하면 우편 발송 후 푸시 알람이 발송됩니다.  
- 차트 아이템은 차트를 생성할 때, 우편 사용 여부를 **사용**으로 해주셔야 목록에 나타납니다.

### 국가 설정

우편 발송 시 국가별로 다른 내용(다른 언어)를 지정하여 우편을 발송할 수 있습니다.  

- 우편 입력란 상단의 **+ 버튼**을 누르시면 해당 국가 코드의 유저에게 다른 내용을 보낼 수 있는 우편 입력란이 생성됩니다.  
- 발송 아이템은 모든 국가에 동일하게 발송됩니다.  
- 국가 선택에 **국가 코드는 현재 유저들에게 설정되어 있는 국가를 기준으로 표시**됩니다.  
  - 우편 내용을 다르게 보내고 싶은 국가 코드를 지닌 유저가 생성되어 있어야 해당 국가 코드가 노출됩니다.  
- 국가 지정은 최대 5개까지 지정할 수 있습니다.  
- 국가 코드를 지니지 않은 유저나 우편엔 국가 설정이 지정되지 않은 유저에게는 **기본** 탭의 내용이 전송됩니다.  

### 우편 발송 대상 설정

발송 대상을 지정할 수 있습니다.  

- 발송 대상을 전체로 하면 전체 유저에게 우편이 발송됩니다.  
- 발송 대상을 선택하면 특정 유저에게만 우편을 보낼 수 있습니다.  
  - 최대 1,000명까지 대상을 지정할 수 있습니다.  

## 관리자 우편 삭제

삭제할 우편을 선택한 후 페이지 상단의 명령 버튼 중 **삭제** 버튼을 클릭해 우편을 삭제할 수 있습니다.  
이미 수령한 우편 아이템은 사라지지 않으나, 수령받지 못한 우편 아이템들은 소멸됩니다.

## 관리자 우편 수신 확인

발송된 우편 이름을 클릭하면 해당 우편의 제목, 내용, 푸시 발송의 내용과 발송 아이템 및 유저들의 수령 여부를 확인할 수 있습니다.  

- 전체 유저가 대상인 우편의 경우 수령한 유저들만 목록에 표시됩니다.  
- 발송 아이템이 없는 전체 대상 우편은 발송 대상을 확인할 수 없습니다.

# 반복 우편

반복 발송된 우편 내역을 확인할 수 있습니다.  

<ConsoleLinkButton text="반복 우편 바로가기" menu="basePost/repeat" feature="우편" title="반복 우편" />

## 반복 우편 삭제

삭제할 우편을 선택한 후 페이지 상단 명령 버튼 중 **삭제** 버튼을 클릭해 우편을 삭제할 수 있습니다.  
이미 수령한 우편 아이템은 사라지지 않으나, 수령받지 못한 우편 아이템들은 소멸됩니다.  

- 발송대기 상태인 반복 우편을 삭제할 경우, 해당 우편의 반복 발송은 종료됩니다.

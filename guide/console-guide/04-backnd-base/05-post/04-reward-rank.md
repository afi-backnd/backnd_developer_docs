# 랭킹 보상

랭킹에 보상을 등록한 경우 랭킹 초기화 시 각 유저에게 랭킹 보상 우편이 발송됩니다.  
발송된 우편은 우편 발송 > 랭킹 보상 탭에서 확인할 수 있습니다.  

<ConsoleLinkButton text="랭킹 보상 바로가기" menu="basePost/reward" feature="우편" title="랭킹 보상" />

## 랭킹 보상 우편 제목

랭킹 보상 제목은 아래와 같은 규칙으로 생성됩니다.  

- {랭킹 이름} 보상({랭킹 구간 시작 - 랭킹 구간 끝})
  ex) 전투력 랭킹 보상(1 - 1000), 길드전 랭킹 보상(2000 - 4000)

전체 보상은 아래와 같은 규칙으로 생성됩니다.  

- {랭킹 이름} 보상(전체 대상)
  ex) 전투력 랭킹 보상(전체 대상)

## 랭킹 보상 우편 발송 내역

<p align="center"><img src="https://developer.thebackend.io/static/img/newconsole/base/우편 관리/뒤끝베이스--우편-관리---랭킹-보상-내역.png" /></p>

랭킹 보상 이름을 클릭하면 아래와 같은 정보를 확인할 수 있습니다.  

- 우편 제목
- 랭킹 보상에 사용된 차트 명
- 보상으로 지급된 아이템 정보
- 보상으로 지급된 아이템 개수
- 우편을 수령한 회원
  > 수령한 유저만 리스트에 표시됩니다.  

:::info 길드 랭킹 보상 우편 수령 주의 안내
길드 탈퇴 이후 길드 랭킹 보상 우편을 조회하는 유저는 수령할 수 없습니다.
- 보상 지급 대상임에도 탈퇴를 한 이후라면 보상 조회 불가 및 수령 불가
- 길드 탈퇴 전 보상 조회를 먼저 진행하고 아직 수령하지 않은 경우 탈퇴 이후에도 해당 보상 수령 가능
:::

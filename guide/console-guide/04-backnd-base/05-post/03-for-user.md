## 유저/캐릭터 간 우편 송수신 내역

뒤끝 콘솔의 우편 관리 - 유저 우편(멀티 캐릭터 사용 시 캐릭터 우편)에서는 유저들 간의 우편 발송과 수령 여부를 확인할 수 있습니다.  

- 유저 간 우편은 발송일로부터 15일 후에 자동으로 삭제되며, 수령일이 **만료됨**으로 표기됩니다.  
- 수령일의 수령 여부 표시는 아래와 같습니다.  
  - 우편 수령 시 : **수령한 날짜(ex:2020.03.17 12:25)**  
  - 우편 미수령 시 : **미수령**  
  - 우편이 미수령인 채로 만료일을 지났을 때 : **만료됨**

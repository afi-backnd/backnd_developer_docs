# 길드 관리

뒤끝 콘솔의 '길드'에서는 유저가 생성한 길드를 관리할 수 있습니다.  



## 길드 목록

길드 목록에서 생성된 길드를 확인할 수 있습니다. 

![길드 관리](/img/docs/guide/guild/guild-01.png)
<!-- <img src="https://developer.thebackend.io/static/img/newconsole/base/길드관리/뒤끝베이스--길드-관리.png" /> -->

## 길드 유형

길드의 유형은 **그룹형**과 **오픈형**으로 나뉘며, [길드 생성(SDK)](https://docs.backnd.com/sdk-docs/backend/base/guild/create-and-join/create/) 시 유형을 지정할 수 있습니다.

- **그룹형 길드**: 그룹 내 유저만 해당 길드를 조회·가입·활동할 수 있습니다.
- **오픈형 길드**: 모든 그룹의 유저가 해당 길드를 조회·가입·활동할 수 있습니다. 길드는 최초 생성된 그룹에 귀속됩니다.

그룹형으로 생성된 길드의 경우, 콘솔에서 오픈형 길드로 전환할 수 있습니다.

![오픈형 길드 전환](/img/docs/guide/guild/guild-03.png)

- 오픈형으로 전환된 길드는 다시 그룹형으로 변경할 수 없습니다.
- 일괄 처리 시, 선택한 길드 중 이미 오픈형인 길드가 있을 경우, 해당 길드는 무시되고 그룹형 길드만 전환됩니다.
- **전체 길드에 적용** 옵션을 체크하면 게임 내 모든 길드를 오픈형으로 일괄 전환합니다.

:::caution 길드 리더보드 + 오픈형 길드 사용 시 주의사항

오픈형 길드는 길드와 길드 마스터, 길드원의 그룹이 서로 다를 수 있습니다.  
따라서 길드 리더보드는 **그룹 구분이 없는 리더보드 운영**을 권장합니다.  
그룹별 리더보드를 운영하는 경우 아래 동작 방식에 유의해 주세요.
- 내 길드 순위 조회(GetMyLeaderboard): 길드 소속 기준으로 조회됩니다.
- 리더보드 전체 순위 조회(GetLeaderboard): 유저 소속 기준으로 조회됩니다.
  - 길드와 다른 그룹에 속한 유저는 해당 길드가 속한 리더보드와 길드 순위를 조회할 수 없습니다.
:::

## 길드 삭제

삭제할 길드를 선택한 후 페이지 상단의 **삭제** 버튼을 눌러 해당 길드를 삭제할 수 있습니다.  

- 길드 삭제 시 모든 길드원은 탈퇴 처리되며 복구가 불가능합니다.  

![길드원 삭제](/img/docs/guide/guild/guild-02.png)
<!-- <img src="https://developer.thebackend.io/static/img/newconsole/base/길드관리/뒤끝베이스--길드-관리---삭제.png" /> -->

## 길드원 목록

:::info 길드 생성 조건/가입 조건
길드 생성 조건/가입 조건은 <a href="/guide/console-guide/backnd-base/guild/setting">해당 문서</a>에서 확인할 수 있습니다.  
:::


해당 길드 이름을 클릭하여 길드에 가입된 길드원을 확인하실 수 있습니다.  

- 닉네임이 없는 유저일 경우, 닉네임이 '**-**'로 출력됩니다.  
- **그룹** 컬럼에서 각 길드원의 소속 그룹을 확인할 수 있습니다.

<img src="https://developer.thebackend.io/static/img/newconsole/base/길드관리/뒤끝베이스--길드-관리---길드원-목록.png" />

## 길드원 등급 변경

해당 길드원 우측에 있는 **수정**버튼을 클릭해 길드원의 등급을 **길드원, 부 길드 마스터, 길드 마스터** 중 하나로 변경하실 수 있습니다.  

- 길드 마스터는 길드에 한 명만 존재하며, 부 길드 마스터는 다수일 수 있습니다.  
- 길드원이 길드 마스터로 등급을 변경할 경우, 기존 길드 마스터는 길드원으로 변경됩니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/base/길드관리/뒤끝베이스--길드-관리---길드원-등급-변경.png" />

## 길드원 탈퇴

탈퇴할 길드원을 선택한 후 상단의 **삭제** 버튼을 클릭하여 길드원을 탈퇴시킬 수 있습니다.  

- 길드 마스터인 유저는 본인 이외의 길드원이 존재할 경우 탈퇴할 수 없습니다.  
- 길드 마스터를 탈퇴시킬 경우, 해당 길드는 길드원이 존재하지 않으므로 삭제됩니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/base/길드관리/뒤끝베이스--길드-관리---길드원-탈퇴.png" />

## 길드의 메타 정보 확인

길드 우측의 메타 버튼을 클릭하여 메타 정보를 확인 및 수정할 수 있습니다.  
수정 시 [리더보드 갱신](#리더보드-갱신) 여부를 함께 선택합니다.

<img src="/img/docs/guide/base/guild/meta.png" />

## 길드의 굿즈 정보 확인

길드 우측의 굿즈 버튼을 클릭하여 현재 가지고 있는 굿즈의 수량을 확인 및 증감할 수 있습니다.  
수정 시 [리더보드 갱신](#리더보드-갱신) 여부를 함께 선택합니다.

<img src="/img/docs/guide/base/guild/goods.png" />

## 리더보드 갱신

메타 정보 또는 굿즈를 수정할 때, 해당 값을 스코어로 사용하는 길드 리더보드를 함께 갱신할지 선택할 수 있습니다.

| 선택지 | 동작 |
|:-----|:-----|
| **갱신 안 함** (기본값) | 길드 데이터만 수정하며, 리더보드 순위에 반영되지 않습니다. |
| **갱신함** | 해당 값을 사용하는 리더보드를 모두 갱신합니다. |

리더보드의 [초기화 주기](/guide/console-guide/backnd-base/rank/create#초기화-주기)에 따라 결과가 달라집니다.

| 초기화 주기 | 갱신 안 함 | 갱신함 |
|:-----|:-----|:-----|
| 매일 · 매주 · 매N월 | 갱신되지 않음 | 갱신됨 |
| 날짜 지정 (시작일 이후 ~ 종료일 이전) | 갱신되지 않음 | 갱신됨 |
| 날짜 지정 (그 외 기간) | 갱신되지 않음 | 갱신되지 않음 |
| 없음 | 갱신되지 않음 | 갱신됨 |

:::info 알아두세요
- **갱신 안 함**은 이번 수정을 리더보드에 즉시 반영하지 않는다는 의미입니다. 이후 해당 길드에 리더보드 갱신을 동반한 쓰기가 발생하면, 그 시점의 길드 데이터를 기준으로 리더보드에 반영됩니다.
- 리더보드가 초기화되는 동안에는 선택과 관계없이 수정할 수 없으며, 안내 모달이 표시됩니다. 연결된 리더보드가 여러 개인 경우 그중 하나라도 초기화 중이면 수정할 수 없습니다.
- 뒤끝 SDK로 메타 정보나 굿즈를 수정하는 경우에는 리더보드가 갱신되지 않습니다.
- 구버전 랭킹과 구버전 실시간 랭킹은 이 선택의 적용 대상이 아니며, 기존 동작을 유지합니다.
:::



## 길드원의 굿즈 내역 확인

굿즈 패널의 내역탭을 클릭하여 굿즈별로 길드원이 기부/사용한 내역을 확인할 수 있습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/base/길드관리/뒤끝베이스--길드-관리---굿즈내역-확인.png" />

### 길드원의 굿즈 상세 내역 확인

길드원을 클릭하여 굿즈 기부/사용 상세 내역을 확인 할 수 있습니다. 굿즈를 사용했을 경우 음수로 표시됩니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/base/길드관리/뒤끝베이스--길드-관리---굿즈-상세내역.png" />

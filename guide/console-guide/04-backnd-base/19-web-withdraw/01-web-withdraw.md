# 회원 탈퇴 웹 링크

## 회원 탈퇴 웹 링크의 생성 및 수정

뒤끝 콘솔 `운영 - 약관 및 정책` 메뉴의 `회원 탈퇴 웹 링크`탭으로 이동 합니다.

<ConsoleLinkButton text="회원 탈퇴 웹 링크 바로가기" menu="basePolicy/close-account-page" feature="약관 및 정책" title="회원 탈퇴 웹 링크" />

![](/img/docs/guide/base/web-withdraw/entry_web_withdraw.png)

* 상단 사용 안내를 반드시 확인하세요. 기능을 사용하기 위한 선행 조건들이 있습니다.
* 회원 탈퇴 웹 링크는 한국어 / 영어로 각각 생성할 수 있습니다.
* `링크 생성하기`를 클릭하고 게임명, 이메일 문의를 입력(선택사항)하세요.
* 구글 로그인 사용 시, Google 로그인, GPGS v2 로그인을 선택할 수 있습니다.
* 생성한 링크의 정보는 수정할 수 있으며 링크를 삭제할 수도 있습니다.

![](/img/docs/guide/base/web-withdraw/create_link.png)

![](/img/docs/guide/base/web-withdraw/create_link_complete.png)

## 회원 탈퇴 페이지

* 뒤끝 콘솔에서 링크를 클릭하면 새창에서 회원 탈퇴 페이지로 리디렉션 됩니다.
* 링크를 생성할 때 입력한 게임명, 이메일 주소를 페이지에서 확인할 수 있습니다.
* 페더레이션 로그인(Google, GPGS, Apple, Facebook)사용 시 해당 로그인 버튼이 생깁니다.
* 유저 로그인을 하면 탈퇴 요청 페이지로 이동합니다.

![](/img/docs/guide/base/web-withdraw/web_link_login.png)

* 해당 페이지에서는 회원 탈퇴와 관련된 개인정보 관련 법률이 안내되고 탈퇴 요청을 보낼 수 있습니다.
* `유저의 계정은 7일 뒤에 탈퇴 처리 됩니다.`

![](/img/docs/guide/base/web-withdraw/web_link_request.png)

# 공지사항

**공지사항**을 등록/수정할 수 있으며 임시 공지를 관리할 수 있습니다.  
SDK에서의 함수 호출은 [개발자 문서-공지사항 리스트 조회](/sdk-docs/backend/base/operation/notice/get-list)를 참고해 주세요.  

:::info
해당 공지 기능은 SDK **5.18.7 이상** 버전부터 이용할 수 있으며, 기존의 구버전 공지도 모두 조회할 수 있습니다.
:::

![공지사항](/img/docs/guide/base/notice_event/notice01.png)

## 공지 생성하기

**공지 생성하기** 버튼을 눌러 새로운 공지사항을 등록할 수 있습니다.   

![공지사항](/img/docs/guide/base/notice_event/notice02.png)


### 공지 이름

- 콘솔에서 운영 시 식별하기 위한 값이며, 목록에 표기됩니다.
- 공지 등록 시 실시간 알림으로 전송되는 값입니다. ([공지 등록 핸들러](https://docs.backnd.com/sdk-docs/backend/base/notify/handler-console/notice/))
- 30자 이하로 입력할 수 있습니다.

### 작성자

- 글 작성 시 로그인 되어있는 계정의 닉네임으로 출력됩니다.  

### 게시 일시

- 즉시 게시 : 등록 즉시 게시됩니다.  
- 예약 게시 : 30분 단위로 예약 설정이 가능하며 현재 시간 이전으로는 설정이 불가합니다.  

### 언어별 작성

- 언어별로 **제목, 내용, 이미지, 버튼(url)**을 각각 작성할 수 있습니다. 제목과 내용은 필수 항목입니다.  
- SDK에서 언어 코드를 기반으로 언어별 공지를 조회할 수 있습니다.
- 기본 언어 탭은 **영어(FALLBACK)** 와 **한국어**로 구성됩니다.
- 언어 목록 하단의 드롭박스에서 언어를 추가할 수 있습니다. (최대 **10개**까지 추가할 수 있습니다.)
- **FALLBACK** 언어는 설정 아이콘을 클릭하여 변경할 수 있으며, FALLBACK으로 지정된 언어는 삭제할 수 없습니다.
- 언어 탭 오른쪽의 삭제 아이콘을 클릭하면 해당 언어와 작성된 공지 내용이 모두 삭제됩니다.

### 제목

- 필수 항목이며 최대 60자까지 입력할 수 있습니다.  

### 내용

- 필수 항목이며 최대 4,000자까지 입력할 수 있습니다.  

### 이미지 첨부

- 공지사항 출력 시, 내용보다 위에 삽입되며 한 장만 첨부가 가능합니다.  
- 최대 크기는 1MB이며 JPG, PNG만 지원합니다.  

### 버튼 및 URL 생성

- 공지사항 출력 시, 내용 아래에 입력한 버튼 명으로 버튼이 생성되며 클릭 시 입력한 URL로 이동합니다.  
- 버튼 이름 항목은 30자 까지, URL 생성 항목은 200자 까지 입력할 수 있습니다.  

### 공개 여부

- 비공개 설정 시 노출되지 않습니다.  

## 공지사항 수정

수정 버튼을 클릭하여 등록된 공지사항을 수정할 수 있습니다.  
- 게시 일시는 과거로 변경이 불가합니다.  

![공지사항](/img/docs/guide/base/notice_event/notice05.png)

## 공지사항 삭제

목록에서 삭제할 공지 선택 후 목록 상단의 **삭제** 버튼을 눌러 삭제할 수 있습니다. 

## 임시공지 관리

임시공지는 일반 공지사항과 별개의 공지사항이며 1건만 가능합니다.  
SDK에서의 함수 호출은 [개발자 문서-임시 공지 조회](/sdk-docs/backend/base/operation/notice/get-temporary-one)를 참고해 주세요.  

임시 공지의 사용목적은 다음과 같습니다.  
- 로그인하지 않은 회원에게 노출하고 싶은 정보가 있는 경우
- 강제 업데이트 문구 혹은 개발자가 임의로 서버를 중단 시킬 시 띄울 문구를 노출하고자 하는 경우
- 공지 내용 항목은 4,000자 까지 입력할 수 있습니다.  
- 언어별로 내용을 작성할 수 있으며, 일반 공지와 달리 클라이언트에서 조회 시 작성된 모든 언어의 내용이 리턴됩니다.

![공지사항](/img/docs/guide/base/notice_event/notice06.png)
![공지사항](/img/docs/guide/base/notice_event/notice04.png)

## 구버전 공지사항

기존에 작성된 공지는 페이지 상단의 버전 변경을 통해 확인할 수 있습니다.  
구버전 공지사항 기능에 대한 자세한 내용은 [공지사항(구버전)](/guide/console-guide/backnd-base/notice/old-notice)을 참고해 주세요.

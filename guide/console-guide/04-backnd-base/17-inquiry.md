# 1:1 문의

뒤끝 콘솔에서 뒤끝 SDK 1대1 기능을 이용해 등록한 문의들을 관리할 수 있습니다.  
SDK에서의 함수 호출은 [개발자 문서-1대1 문의](/sdk-docs/backend/base/operation/question/using-webview/one-on-one)를 참고해 주세요.  

<ConsoleLinkButton text="1:1 문의 바로가기" menu="baseInquiry" feature="1:1 문의" title="1:1 문의" />

- 국가 및 언어 정보를 조회하기 위해서는 SDK 5.11.0 이상 버전을 사용하셔야 합니다.  

![1:1 문의 관리](/img/docs/guide/inquiry/inquiry-01.png)

## 문의 확인

해당 문의를 클릭하여 문의의 내용을 확인할 수 있습니다.  
- 문의에 첨부된 첨부 파일은 클릭하여 다운로드하실 수 있습니다.  
- 국가 및 언어 정보를 조회하기 위해서는 SDK 5.11.0 이상 버전을 사용하셔야 합니다.  

![1:1 문의 확인](/img/docs/guide/inquiry/inquiry-02.png)
<!-- <img src="https://developer.thebackend.io/static/img/newconsole/base/일대일 문의/뒤끝베이스-일대일-문의---문의-확인.png" /> -->

## 문의 답변 등록

**답변**란에 내용을 작성한 후 **확인** 버튼을 누르시면 답변이 등록됩니다.  
답변 등록이 완료되었을 경우, 상태가 **답변완료**로 변경됩니다.  

![1:1 문의 답변](/img/docs/guide/inquiry/inquiry-03.png)
<!-- <img src="https://developer.thebackend.io/static/img/newconsole/base/일대일 문의/뒤끝베이스-일대일-문의---문의-답변-등록.png" /> -->

## 문의 설정

페이지 상단 명령 버튼 중 **문의 설정** 버튼을 눌러 문의 작성 시 기본 양식을 설정합니다.  
게임 내 뒤끝 1:1 문의 기능 내용란에 해당 내용이 기본 입력됩니다.  
- 언어별 문의 설정은 SDK 5.11.0 이상 부터 사용 가능합니다.  

![1:1 문의 양식](/img/docs/guide/inquiry/inquiry-04.png)
<!-- <img src="https://developer.thebackend.io/static/img/newconsole/base/일대일 문의/뒤끝베이스-일대일-문의---문의-설정.png" /> -->

## 문의 삭제

페이지 상단 명령 버튼 중 **삭제** 버튼을 눌러 문의를 삭제할 수 있습니다.  

![1:1 문의 삭제](/img/docs/guide/inquiry/inquiry-05.png)

# 환불 관리

뒤끝 콘솔의 **환불 관리** 메뉴에서는 구글 플레이, 앱스토어, 원스토어에서 발생한 환불 완료 건을 통합 조회하고 처리 상태를 관리할 수 있습니다.  
환불 완료 웹훅이 수신된 시점부터 데이터가 기록되며, 회수 알림 발송과 유저 차단 기능을 통해 환불 운영 비용을 절감할 수 있습니다.

:::info 환불 기능 사용 전 확인 사항
환불 관리 기능을 이용하려면 뒤끝 베이스 **[SDK 연동](https://docs.backnd.com/sdk-docs/backend/base/start-up/)** 및 **[스토어별 웹훅 등록](/guide/console-guide/backnd-base/refund/setting)**이 필요합니다.  
요금 및 기능 스펙은 **[환불 관리 요금제](https://backnd.com/ko/pricing/refund/)**를 참고해 주세요.
:::

## 환불 목록 선택

목록에서 하나 이상의 항목을 선택하면 아래 액션을 일괄 실행할 수 있습니다.

![환불 관리 목록 선택](/img/docs/guide/refund/refund3.png)

- **상태 변경하기**
  - 환불 건의 처리 상태를 변경합니다.
  - 변경 가능 상태: 환불완료, 회수완료, 회수제외, 기타
  - 이전 상태에 관계없이 자유롭게 변경할 수 있습니다.
- **알림 발송하기**
  - 선택한 유저의 클라이언트로 재화 회수 알림을 실시간으로 발송합니다.
  - 알림 발송 후 처리 상태는 자동으로 '알림발송'으로 변경됩니다.
  - [실시간 알림 수신 SDK 문서 확인하기](https://docs.backnd.com/sdk-docs/backend/base/notify/handler-user/post)
- **유저 차단하기**
  - 선택한 유저를 차단합니다.
  - 차단 유저는 유저 UUID 좌측에 차단 아이콘이 표기됩니다.
  - 유저 UUID 기준으로 차단되며, 차단 해제 필요 시 [유저 접근 관리](/guide/console-guide/backnd-base/access-user/blocking)메뉴에서 처리할 수 있습니다.


:::info PRO 전용 / 베이스 인증 유저 전용
알림 발송하기, 유저 차단하기는 **PRO 요금제** 및 **베이스 인증 유저**에게만 지원됩니다.
:::

## 차단 제외 등록

![차단 제외 등록](/img/docs/guide/refund/refund4.png)

환불 발생 시 자동 차단이 적용되지 않도록 특정 주문을 미리 제외 등록할 수 있습니다.

- 주문 ID를 입력하여 등록합니다. 등록된 주문은 **차단제외** 상태로 목록에 표시됩니다.
- 입력한 주문 ID가 영수증 검증 목록에 추가되어 있지 않으면 등록이 불가합니다.
- 이후 해당 주문의 환불 웹훅이 수신되면 상태는 **환불완료**로 변경됩니다. 
- **차단제외** 탭에서 차단제외했던 환불 건을 조회할 수 있습니다.

:::info PRO 전용 / 베이스 인증 유저 전용
차단 제외 등록은 **PRO 요금제** 및 **베이스 인증 유저**에게만 지원됩니다.
:::

## 검색

상태, 기간, 닉네임, 스토어, 유저 UUID, 주문 ID로 환불 내역을 검색할 수 있습니다.

### 상태 탭

- 목록 상단의 탭을 선택하여 처리 상태별로 조회할 수 있습니다.  
- 각 상태의 의미는 [목록 > 처리 상태](#처리-상태)를 참고해 주세요.

### 기간 및 조건 검색

- 환불 완료일(웹훅 수신일) 기준으로 기간을 조회할 수 있습니다. 
- 기간은 최대 **3개월**까지 조회 가능합니다.
- 닉네임, 스토어, 유저 UUID, 주문 ID를 입력하여 조회할 수 있습니다.
- 검색 시 **초기화** 및 **CSV 다운로드** 버튼이 활성화됩니다.



 <br/>

## 지원 범위 안내

환불 관리는 요금제 및 유저 인증 여부에 따라 지원 기능이 상이합니다.  
여기서 **인증 유저**는 베이스 SDK에서 로그인(유저 인증)이 완료된 유저를 의미합니다.

| 구분 | 기능 | BASIC | PRO | 인증 | 미인증 |
|:---:|------|:-----:|:---:|:---:|:-----:|
| 콘솔 | 영수증 검증 > 조회 | O | O | O | O |
| 콘솔 | 환불 > 조회, 상태 변경 | O | O | O | O |
| 콘솔 | 환불 > 실시간 알림 발송 | X | O | O | X |
| 콘솔 | 환불 > 설정 > 알림 자동 발송 | X | O | O | X |
| 콘솔 | 환불 > 유저 차단하기 | X | O | O | X |
| 콘솔 | 환불 > 자동 차단하기 | X | O | O | X |
| 콘솔 | 환불 > 차단 제외하기 | X | O | O | X |
| 콘솔 | 환불 > CSV 다운로드 | X | O | O | O |
| SDK | 영수증 검증 | O | O | O | O |
| SDK | [환불 상태 조회](https://docs.backnd.com/sdk-docs/backend/base/receipt/refund/get-refund-list) | X | O | O | O |
| SDK | 환불 상태 업데이트 | X | O | O | O |

### 미인증 유저 지원

- 베이스 SDK의 유저 인증(로그인)을 사용하지 않는 경우에도 환불 내역 조회 및 상태 변경이 가능합니다.
- 단, 유저 데이터가 없으므로 영수증 검증 시 '유저 UUID' 값을 필수로 전송해야 합니다.
- 미인증 유저의 경우 닉네임 정보가 저장되지 않으며, 회수 알림 발송·유저 차단·차단 제외 등록은 사용할 수 없습니다.

# 구버전 랭킹 정보

:::danger 구버전 랭킹 생성 중단 안내
구버전 랭킹 테이블은 더이상 생성하실 수 없습니다.  
기존에 미리 생성되어 있는 랭킹은 정상적으로 이용이 가능합니다.  
새로 랭킹을 생성하는 경우 신규 랭킹을 사용해 주세요.  
:::

랭킹은 하루 네 번(한국시간 06:00, 12:00, 18:00, 24:00) 게임 정보를 바탕으로 산정됩니다.  

## 랭킹 산정

- 랭킹은 하루 네 번 **한국시간 06:00, 12:00, 18:00, 24:00** 산정됩니다.  
- 랭킹 산정은 랭킹 생성 이후 게임 정보에 저장된 값만 포함됩니다.  
- 동점이 발생하는 경우 공동 순위로 산정되며, 다음 순위는 **이전 순위 +(동점자 수)**입니다.  
  - 공동 순위의 경우, 랭킹 정렬 기준(오름차순, 내림차순)과 같은 기준으로 gamer_id(회원번호)를 사전식 순서로 정렬합니다.

# 랭킹 보상

:::danger 구버전 랭킹 보상 생성 중단 안내
구버전 랭킹 테이블은 더이상 생성하실 수 없습니다.  
기존에 미리 생성되어 있는 랭킹은 정상적으로 이용이 가능합니다.  
새로 랭킹을 생성하는 경우 신규 랭킹을 사용해 주세요.  
:::

랭킹 순위에 대한 보상을 지급할 수 있는 기능입니다.  

## 랭킹 보상

- 랭킹 보상 테이블
  - 특정 랭킹에 보상할 아이템과 수량을 지정해 저장하는 테이블입니다.  
  - 최대 100명(1등 ~ 100등)까지에 한해 등록 및 지급이 가능합니다. 동점자 발생으로 보상 대상이 100명을 초과할 경우 100명 후부터는 지급되지 않습니다.  
  - 보상 아이템은 차트에 등록되어 있는 파일에서 설정할 수 있습니다.

# 뒤끝펑션

## 뒤끝펑션 활성화

뒤끝펑션을 이용하려면 페이지 하단의 **뒤끝펑션 활성화** 버튼을 눌러 기능을 활성화해야 합니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/function/뒤끝펑션--활성화.png" />

## 인증키

화면 상단의 인증키 항목에서 뒤끝펑션 사용 시 필요한 인증키를 확인 및 복사할 수 있습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/function/뒤끝펑션--인증키.png" />

## 함수 목록

뒤끝펑션 개발 툴을 이용해 등록한 뒤끝펑션 목록을 볼 수 있습니다.  

- 함수명으로 검색할 수 있습니다.  
- 페이지 상단의 명령 버튼 중 **새로 고침** 버튼을 클릭해 함수 목록을 갱신할 수 있습니다.  
- 함수를 선택한 후 페이지 상단의 명령 버튼 중 **삭제** 버튼을 클릭해 함수를 삭제할 수 있습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/function/뒤끝펑션--함수-목록.png" />

## 로그 스트림

등록된 함수명을 클릭해 해당 함수의 로그 스트림을 확인할 수 있습니다.  

- **새로 고침 버튼**을 클릭해 로그 스트림을 갱신할 수 있습니다.  
- 로그 스트림을 검색할 수 있습니다.  
- 삭제할 로그 스트림을 선택한 후 **삭제** 버튼을 클릭해 삭제할 수 있습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/function/뒤끝펑션--로그스트림.png" />

## 로그 스트림 - 상세 보기

로그 스트림을 클릭해 상세 로그를 확인할 수 있습니다.  

- 최대 분 단위까지 기간을 특정하여 검색할 수 있습니다.  
- **새로 고침** 버튼을 클릭해 상세 로그를 갱신할 수 있습니다.  
- CSV 파일로 상세 내역을 다운로드할 수 있습니다.  

<img src="https://developer.thebackend.io/static/img/newconsole/function/뒤끝펑션--로그스트림-상세보기.png" />

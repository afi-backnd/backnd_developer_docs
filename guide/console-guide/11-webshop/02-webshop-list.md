---
title: 지급 내역
---

웹숍을 통해 지급된 **아이템 지급 우편의 상태를 조회하고 관리**할 수 있습니다.  
결제 완료 후 발송된 우편의 처리 상태를 기준으로, 지급·수령·회수 여부를 확인할 수 있습니다.

![지급 내역](/img/docs/guide/webshop/webshop2.png)
- 지급 내역 목록에는 **웹숍으로부터 전달된 결제 정보**를 기준으로 다음 항목들이 표시됩니다.
    - 웹숍, 주문 ID, 아이템 ID, 수량, 가격, 결제자, 수신자
- **발송일**, **수령일**은 **뒤끝 서버에서 우편을 처리한 시점**을 기준으로 표시됩니다.
    - 이를 통해 실제 게임 서버 기준의 지급·수령 이력을 확인할 수 있습니다.

<br/>

### 검색 및 필터

다음 조건으로 지급 내역을 검색할 수 있습니다.

| 검색 조건 | 설명 |
| --- | --- |
| 텍스트 검색 | 결제자, 수신자, 주문 ID, 아이템 ID 중 선택하여 검색 |
| 웹숍 종류 | 전체 / Newplay / Xsolla |
| 수령 상태 | 전체(기본값) / 미수령 / 수령 / 회수 / 만료 |
| 발송일 기간 | 기본 3개월 전 ~ 오늘, 최대 1년 범위 조회 가능 |

<br/>

### 지급 상태

| 상태 | 설명 |
| --- | --- |
| 미수령 | 우편이 발송되었으나 아직 유저가 수령하지 않은 상태 |
| 수령 | 유저가 우편을 수령 완료한 상태 |
| 회수 | 환불·취소 등으로 우편이 회수된 상태. 유저가 우편함에서 조회하거나 수령할 수 없습니다. |
| 만료 | 수령 가능 기간(30일)이 경과하여 만료된 상태. 만료된 우편은 수령할 수 없습니다. |

<br/>

### 미수령 우편 회수

- 상태가 **미수령**인 우편에 한해 체크 후 회수 처리가 가능합니다.
- 회수 처리된 우편은 유저가 우편함에서 조회하거나 수령할 수 없습니다.
- 이미 회수된 우편은 다시 지급할 수 없습니다.
- 회수 처리 직전에 유저가 우편을 수령한 경우, 회수는 실패하며 수령 완료 상태로 처리됩니다.

<br/>

### 주문 취소 시 자동 회수 (엑솔라)

엑솔라의 경우, 주문 취소(`order_canceled`) 이벤트가 수신되면, 뒤끝 서버에서 자동으로 회수 처리를 진행합니다.  
단, 이미 수령한 우편의 경우 회수되지 않으며, 별도 처리를 진행해야 합니다.


<br/>

### CSV 다운로드

- 웹숍별 지급 내역을 CSV 파일로 다운로드할 수 있습니다.
- 다운로드 시 비밀번호 확인이 필요합니다.
- 기간 설정 및 사유 입력 후 다운로드할 수 있으며, 다운로드 내역도 별도로 조회할 수 있습니다.
- 최대 1년 범위의 데이터를 다운로드할 수 있습니다.

<br/>

### 웹숍 API 전송 이력 확인

웹숍 연동 과정에서 발생한 **API 요청 및 처리 이력**은 뒤끝 콘솔의 '**분석 > 로그'** 메뉴에서 확인할 수 있습니다.  
로그 메뉴에서는 웹숍 관련 행동 유형을 선택하여 필요한 이력만 조회할 수 있습니다. 

※ 웹숍 운영 관련 유형

| 웹숍 | 행동 유형 | 케이스 | 설명 |
| --- | --- | --- | --- |
| 뉴플레이 | NEWPLAY_USER_LOOKUP | 유저 조회 | 웹숍에서 유저 존재 여부 확인 |
| 뉴플레이 | NEWPLAY_AUTHCODE_SENT | 인증코드 전송 | 인증번호 우편 발송 결과 |
| 뉴플레이 | NEWPLAY_DELIVERY_RESULT | 지급 처리 결과 | 아이템 지급 우편 발송 결과 |
| 뉴플레이 | NEWPLAY_GAME_DATA_LOOKUP | 게임정보 조회 | 웹숍에서 게임정보 조회 |
| 뉴플레이 | NEWPLAY_LEADERBOARD_LOOKUP | 리더보드 조회 | 웹숍에서 리더보드 조회 |
| 엑솔라 | XOLLA_USER_VALIDATION | 유저 조회 | 웹숍에서 유저 존재 여부 확인 |
| 엑솔라 | XOLLA_ORDER_PAID | 지급 처리 결과 | 아이템 지급 우편 발송 결과 |
| 엑솔라 | XOLLA_ORDER_CANCELED | 회수 처리 결과 | 주문 취소에 따른 우편 회수 결과 |

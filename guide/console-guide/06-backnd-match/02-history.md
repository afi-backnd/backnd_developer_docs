# 매치 기록

뒤끝 콘솔에서 유저들의 각 매치 타입 - 매치 모드 타입 별로 구분 지어 매칭 기록을 열람할 수 있습니다.  

<ConsoleLinkButton text="매치 기록 바로가기" menu="realtimeMatch/record" feature="뒤끝매치" title="매치 기록" />

<img src="https://developer.thebackend.io/static/img/newconsole/match/뒤끝매치--매치-기록.png" />

기간 없음 매치의 경우 **기록일**은 해당 매치 **생성일**입니다.  

매치 기간을 설정했을 경우 **기록일**은 매치 **초기화 날짜(시즌 시작 날짜)**입니다.

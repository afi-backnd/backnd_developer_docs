# guide 개요

TheBackend 사용 가이드 모음. 콘솔 설정부터 SDK 연동까지 단계별로 안내합니다.

## 디렉터리

| 디렉터리 | 설명 |
|---|---|
| [getting-started/](./getting-started/) | 뒤끝 시작하기 — 콘솔 가입, 기능별 사용법, 튜토리얼 |
| [console-guide/](./console-guide/) | 콘솔 UI 상세 가이드 |

## getting-started/ 주요 내용
- 게임 운영 기본 흐름 (02-how-to-use/)
- 유저, 랭킹, 길드, 쿠폰, 채팅, 매치, 펑션 등 기능별 사용법
- 간단 비행기 게임 전체 구현 튜토리얼 (04-tutorial/)
- DB 최적화, 비용 절감 가이드 (03-detail-backnd/)

## console-guide/ 주요 내용
- 서버 설정 (프로젝트, 인증, 스토어, 푸시)
- 계정 및 요금제 관리
- 백엔드 베이스/매치/펑션/데이터베이스/채팅/월드 콘솔 사용법
- 웹샵 설정
